## 3. 글자 · 간격 · 모서리 · 크기

- 글꼴: 캔버스는 Gothic A1(제안). 구현은 로컬 대체 글꼴 유지 가능. 한 글꼴의 굵기로 위계를 나눈다(제목 800, 본문 400~600).
- 크기: 화면 제목 30~34 · 단계 제목 26 · 섹션 제목 20 · 카드 제목 17~18 · 본문 15(줄간 1.6) · 보조 14 · 메타 13 · **최소 12**. 입력값은 16 이상.
- 숫자는 `font-variant-numeric: tabular-nums`, 제목은 `text-wrap: balance`.
- 간격: 4px 단위(4·8·12·16·20·24). 화면 좌우 16, 카드 안쪽 16~18, 카드 사이 10~12, 섹션 사이 14~18.
- 모서리: 태그 6 · 입력·안내 상자·요약칸·알림 12 · 카드(혜택·지역·코스·조건 카드) 20 · 하단 메뉴 24 · 버튼과 칩 알약형(999).
- 조작 크기: 최소 44×44, 주 버튼 높이 52, 입력 48~52, 하단 메뉴 칸 52. 하단 메뉴 아래 여백 `calc(14px + env(safe-area-inset-bottom))`.

## 4. 컴포넌트

### 배지와 표시

| 종류 | 모양 | 문구 |
| --- | --- | --- |
| 후보 | 코발트 알약 + 흰 글자 + 체크 아이콘 | 조건이 맞는 후보 |
| 추가 확인 필요 | `#FFE9C7` 알약 + `#8A4500` 글자 + 물음표 아이콘 | 추가 확인 필요 |
| 알려진 조건 불일치 | 흰 알약 + `#55575C` 1.5px 테두리 + 빼기 아이콘 | 알려진 조건 불일치 |
| 현재 기간 아님 | `#E3E5E9` 알약 + 시계 아이콘 | 현재 기간 아님 |
| 공고 상태 | 배지 아님. 절취선 아래 굵은 글자 + 쉼표 + 기간 | 공고 기간 중, 11-08까지, 마감 확인 / 상시 제도 안내 / 진행 확인 필요 / 시작 전 / 기간 종료 |
| 학생 경로 있음 | `#ECEEF1` 사각(모서리 8) + 학사모 아이콘 | 학생 경로 있음 (공식 근거가 있는 혜택만) |
| 가상 표시 | 점선 `#8E9197` 사각(모서리 6), 12px | 가상 예시 (신청 불가) / 가상 지역 / 가상 경험 / 가상 코스 |
| 지역 적합 | `#EEF1FD`+`#2A3FB8` 또는 확인 필요 색, 혜택 배지보다 작게 | 시간·도보·예산 안 / 맞는 경험 부족 |

모든 상태는 색 외에 아이콘과 글자로 구분한다.

### 혜택 티켓 카드

- 접힘: 상태 배지(+학생 경로·가상 표시) · 분야 → 혜택 이름(17~18/800) → 한 줄 이유(14, `#3A3C40`) → **반원 홈 절취선** → 공고 상태와 기간 + ‘자세히 ⌄’.
- 반원 홈: 지름 16px 원 두 개를 카드 양끝 밖으로 8px 내보내고(바탕색 `#ECEEF1`), 사이에 2px 점선 `#D3D6DB`. 카드는 `overflow: hidden`이라 반원으로 보인다. **혜택 카드에만** 쓴다.
- 펼침: `#F6F7F9` 영역에 ‘맞는 이유 / 확인 이유 / 학생 경로 / 남은 확인 / 기간 / 참고’ 표(이름표 64px 열), 출처와 확인일(12px), ‘공식 안내 열기’(코발트, 외부 링크 아이콘). 국립현대미술관처럼 대안 조건이 있으면 ‘조건 비교 전체 보기’를 더한다.
- 요약 버튼은 `button` + `aria-expanded` + `aria-controls`. 한 번에 하나만 펼친다(구현 P22와 같음).

### 내 조건 카드

흑연 카드(모서리 20). 위에 ‘비교에 쓰는 내 조건’(가상 입력이면 ‘(가상 입력)’), 아래 3칸 `dl`: 나이 / 거주 / 학생. 학생 값 아래 ‘본인 입력’(12px, `#C9CBD0`). 미입력이면 세 칸 모두 ‘미입력’. 오른쪽에 코발트 ‘수정’ 버튼(44px 이상). 저장하지 않은 변경이 있으면 카드 안에 ‘변경한 설정은 아직 저장하지 않았어요.’와 ‘내 설정에 저장’ 버튼.

### 그 밖의 컴포넌트

- 상태별 바로가기: 4칸 그리드(모서리 12). 개수가 있으면 흰 바탕, 0이면 `#8E9197` 테두리만.
- 필터 칩: 알약, 높이 44. 선택은 흑연 바탕 + 체크, 기본은 흰 바탕 + `#8E9197` 테두리. 가로로 넘치면 오른쪽으로 밀어 본다.
- 단계 표시줄: 5칸 막대(완료 코발트, 남은 칸 `#8E9197`) + ‘3 / 5’. `role="progressbar"`.
- 하단 메뉴: 흑연 둥근 막대(모서리 24) 안 4칸, 현재 탭은 코발트 칸 + `aria-current="page"`.
- 입력: 이름 항상 표시, 테두리 `#8E9197` 1.5px, 입력 중 코발트 2px, 오류 `#B3261E` 2px + 아래 오류 문구(아이콘 + 해결 방법). 숫자 입력은 단위와 ‘비우기’ 버튼.
- 선택지 타일: 라디오와 이름이 한 터치 영역. 선택은 코발트 2px + `#EEF1FD`.
- 피드백: 저장 완료 알림(흑연, `role="status"`) · 한도 근접 주의(`#FFF4E0`) · 저장 실패(`#B3261E` 테두리, `role="alert"`, ‘다시 저장’) · 불러오기 오류(흑연 테두리, ‘다시 시도’) · 빈 결과(점선 상자, ‘필터 초기화’).

## 5. 문구 규칙

- 후보는 “입력한 조건이 확인된 기준과 맞아요”까지만 말한다. ‘지원 확정’, ‘받을 수 있어요’는 쓰지 않는다.
- 미입력은 “입력하면 비교할 수 있어요”로 안내한다. ‘조건 미달’로 쓰지 않는다.
- 출생연도·시군구·학부생 여부처럼 지금 필드로 알 수 없는 조건은 ‘확인 필요’로 두고 이유를 쓴다.
- 이름표는 문장 위 한 줄에 둔다(‘맞는 이유’ 다음 줄에 문장). 메타 문장은 쉼표로 잇고 가운뎃점을 쓰지 않는다. ‘거주 시·도’ 같은 고유 표기는 예외.
- 이유 문장에 화살표를 쓰지 않는다. 실제 순서(동선·경로)만 화살표 허용.
- 버튼은 하는 일을 그대로: ‘코스 저장’ → 알림 ‘저장했어요’, ‘내 설정에 저장하고 비교’, ‘이번 비교에만 적용’.
- 오류는 무엇이 잘못됐고 어떻게 고치는지와 함께, 남아 있는 것을 알린다(“입력한 조건과 필터는 그대로 있어요”).
- 저장 중은 ‘저장 중…’(말줄임표 문자).

## 6. 접근성 · 상호작용

- 모든 버튼·링크·입력에 보이는 포커스 링: `:focus-visible { outline: 3px solid #3651E8; outline-offset: 2px }`.
- 입력에 `name`, 인증과 무관한 칸은 `autocomplete="off"`. 오류는 `aria-invalid` + `aria-describedby`.
- 입력 오류가 있어도 제출 버튼은 켜 두고, 누르면 첫 오류 필드로 포커스. (현재 구현의 비활성 처리와 다름)
- 시트: `dialog`, 포커스 가두기, Esc 닫기, 닫으면 여는 버튼으로 포커스 복귀, `overscroll-behavior: contain`, 아래 버튼 여백에 안전 영역.
- 결과 수·저장 결과·순서 이동은 `aria-live`로 알린다.
- `touch-action: manipulation`, 누름·호버 반응, `prefers-reduced-motion`에서 전환·애니메이션 끔.
- 숫자·날짜는 `Intl.NumberFormat`·`Intl.DateTimeFormat`. 긴 이름은 카드에서 2줄까지.
