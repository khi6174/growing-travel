웹 인터페이스 규칙 점검

반영함 캔버스 화면에 바로 고침 · 개발 때 그림으로는 표현이 안 되는 구현 사항 · 결정 필요 사용자 판단

처리발견바꾼 내용 · 기준
반영함모든 화면에 키보드 포커스 표시가 없었어요버튼·링크·입력에 코발트 3px 포커스 테두리(:focus-visible)를 넣었어요
반영함하단 메뉴와 시트 버튼이 아이폰 홈 막대에 가려질 수 있었어요아래 여백에 기기 안전 영역(safe-area-inset-bottom)을 더했어요
반영함입력칸에 이름(name)과 자동 완성 설정이 없었어요나이·거주·출발역·날짜·예산·코스 이름에 이름을 붙이고, 비밀번호 관리자가 끼어들지 않게 자동 완성을 껐어요
반영함조건 수정 시트를 끝까지 넘기면 뒤 화면까지 함께 움직일 수 있었어요시트 안에서만 스크롤이 멈추게 했어요(overscroll-behavior: contain)
반영함입력 오류가 있으면 적용 버튼을 비활성으로 막았어요버튼은 켜 두고, 누르면 오류가 난 만 나이 칸으로 이동한다고 안내해요. 막힌 버튼은 왜 안 되는지 알기 어려워요
반영함누를 때·올릴 때 반응, 숫자 정렬, 제목 줄바꿈누름·호버 반응, 터치 지연 방지, 숫자 같은 폭(tabular-nums), 제목 줄 균형(text-wrap: balance), 움직임 줄이기 설정 존중을 넣었어요
개발 때‘30,000원’, ‘2026-10-24’를 직접 적었어요숫자·날짜는 Intl.NumberFormat·Intl.DateTimeFormat으로 만들어요
개발 때저장 중 상태를 그리지 않았어요‘저장 중…’처럼 말줄임표 문자(…)를 쓰고, 그동안 버튼을 한 번 더 누를 수 없게 해요
개발 때조건을 바꾸고 저장하지 않은 채 떠날 수 있어요화면을 떠나기 전에 ‘저장하지 않은 조건이 있어요’를 확인해요
개발 때긴 혜택 이름·코스 이름 처리카드 제목은 2줄까지 보이고 나머지는 줄임. 이름 전체는 펼친 영역에서 보여요
개발 때본문으로 건너뛰기 링크가 없어요화면 맨 앞에 ‘본문으로 건너뛰기’를 두고 평소엔 숨겨요
결정 필요필터와 펼친 카드가 주소(URL)에 남지 않아요공유·뒤로 가기 때 같은 화면으로 돌아오게 할지 정해야 해요
결정 필요다크 모드가 없어요지원하면 색 토큰을 한 벌 더 만들어야 해요

영어 제목 대문자 규칙(Title Case)은 한국어 화면에 해당하지 않아 제외했어요. 점검은 화면 코드를 읽어서 했고, 실기기·화면 낭독기로 확인한 결과는 아니에요.

시각 개선 제안 결정 필요

frontend-design이 꼽은 ‘자동 생성처럼 보이는 기본값’과 겹치는 부분이에요. 1~4번은 2026-10-26에 화면에 반영했고, 5·6번(코발트·글꼴)은 그대로 두기로 했어요.

흐름에서 다시 본 점 결정 필요

  • 코스 순서 바꾸기: bencium은 끌어서 옮기기를 권하고, Vercel 규칙은 끌기만 있으면 안 되고 버튼·키보드 대안이 필요하다고 해요. 지금 위·아래 버튼은 그대로 두고, 끌어서 옮기기를 더할지 정하면 돼요.
  • 코스 삭제: 경험 빼기는 바로 반영돼요. 실수로 뺐을 때 ‘되돌리기’ 알림을 몇 초 보여주는 안을 제안해요.
  • 불러오는 중: 혜택 목록이 늦게 뜰 때 빈 화면 대신 카드 모양 자리 표시를 보여주는 안을 제안해요(아직 그리지 않음).
