# 구현 이력과 이번 전달 작업의 검사 범위

작성일: 2026-10-24. 이 문서는 원프로젝트 `plans/07_PERSONALIZED_BENEFITS.md`와 `plans/07_DOC_CHECK_RESULTS.json`에 남긴 직전 구현 결과를 요약한다. 앱 코드와 해당 전체 기록은 이 ZIP에 포함하지 않는다.

## 직전 구현에서 실제 확인한 것

- `node --test tests/*.test.mjs`: 72개 통과, 실패·취소·건너뜀 0개. 개인 조건 누락/오류, 연령 경계, 거주 조건, 학생 자기 보고, OR 조건, 근거 부족, 날짜, 기존 저장본 호환 등을 포함한다.
- 샌드박스 실행 중 로컬 서버 연결 제한(EACCES)으로 1개 실패한 뒤, 허용된 환경에서 전체 72개 통과를 확인했다.
- 문서 정적 검사: Markdown 27개, 로컬 참조 233개, 정의 80개, 수용 기준 13개. 실패 0개, 기존 전달 사본 2개 해시 일치. 이는 당시 프로젝트 상태의 결과이며 새 ZIP의 파일 수가 아니다.
- 실제 브라우저에서 조건 변경에 따른 후보/추가 확인/불일치, 필터 결과 0개, 기존 코스 재열람 후 현재 혜택 기준 유지, 새로고침으로 기존 설정 복원을 확인했다. 검사용 입력은 저장하지 않았다.
- 390×844 뷰포트에서 가로 넘침이 없음을 확인했고 수집된 브라우저 오류·경고는 0건이었다.

## 확인하지 않은 것과 미확정

실제 휴대폰·가상 키보드·스크린리더, 실제 신청·잔여 예산·재고·신분/학적 증빙은 검사하지 않았다. 공식 자료 자동 갱신, 서버 저장, 계정, 운영 AI 모델·네이티브 스택·최종 디자인은 후속이다. 가상 여행 장소와 코스의 운영·방문·후기도 검증하지 않았다.

## 이번 압축 작업

이번 작업은 기존 전달서·요청문·PNG를 선별하고, 대상별 첨부 안내를 작성해 ZIP으로 묶는 일이다. 앱 코드를 변경하거나 자동 앱 검사 72개를 다시 실행하지 않았다. 원프로젝트는 Git 저장소가 아니어서 Git 기준 변경 비교는 불가능했다.

패키지 문서의 내부 링크, 두 요청문 분리, PNG 원본 해시, ZIP 파일 목록과 파일별 해시를 검사한다. 외부 URL 전체 연결 검사나 혜택 공고 재조사는 이번 포장 검사의 범위가 아니다. `MANIFEST.json`은 파일 목록과 SHA-256을 제공한다.

혜택 근거 문서는 원프로젝트 `docs/12_BENEFIT_MATCHING_SOURCES.md`를 전달용으로 복사했다. 패키지에 없는 과거 문서의 상대 링크만 ‘원프로젝트 참고’ 텍스트로 바꾸고 공식 외부 URL·조건·확인 한계는 유지했다. 두 핵심 전달서는 파일 원문을 복사했으며 요청문은 기존 `handoff/claude/PROMPTS.md`의 두 코드 블록에 화면 사용 설명을 덧붙였다.
