# 12. 개인 조건 비교를 위한 혜택 근거

> 전달용 사본: 원프로젝트 과거 문서 상대 링크만 참고 파일명으로 바꾸었습니다. 공식 URL·조사 내용·확인 한계는 원문을 유지했습니다.

확인일: 2026-10-24 (Asia/Seoul). 별도 전달 패키지 docs 원문 미확보. 기존 출처 장부 (원프로젝트 docs/10_BENEFIT_SOURCES.md, 이 ZIP 미포함)와 혜택 탭 출처 (원프로젝트 docs/11_BENEFITS_CATALOG_SOURCES.md, 이 ZIP 미포함)를 보존하며, 이번 개인 조건 비교에 쓸 수 있는 근거와 한계를 보완한다. 이 문서는 실제 방문·신청·할인 적용의 증거가 아니다.

## 비교 원칙

- `age`는 사용자가 입력한 현재 만 나이다. 출생연도나 생년월일로 바꾸어 저장하지 않는다. 출생연도 기준 사업은 추가 확인 대상으로 둔다.
- `residenceRegion`은 자기 보고한 거주 시·도다. 출발지·여행 목적지·주민등록 인증 결과와 다르다. 사용 장소의 지역 제한을 거주지 제한으로 바꾸지 않는다.
- `studentStatus`는 선택적 자기 보고다. 미입력을 비대학생으로 보지 않는다. 기존 대학생 입력만으로 학부/대학원·재학/휴학·증빙을 구분하지 않는다.
- 입력 조건과 공식 안내의 비교 결과, 공고 일정, 실제 증빙·잔여 물량 확인은 별개다. ‘조건이 맞는 후보’도 수혜 확정이 아니다. 회원·신분 증빙 같은 최종 확인사항을 후보 설명에 유지한다.
- 본문 미열람·출생연도 불명·필수 세부 조건 불명은 ‘추가 확인 필요’ 사유다. 확인하지 못한 조건을 임의의 나이·지역·학생 가점으로 만들지 않는다.
- 아래 공식 혜택은 가상 여행지·가격·지역 혜택과 분리한다. 공식 혜택으로 가상 코스 비용을 차감하지 않는다.

## 추가할 수 있는 대학생 관련 문화 안내

**국립현대미술관 서울 무료관람 대상 안내**를 확보했다. [국립현대미술관 서울 관람정보](https://www.mmca.go.kr/visitingInfo/seoulInfo.do)의 공개 본문을 직접 읽었다. 무료대상 목록에는 ‘만 24세 이하, 만 65세 이상’과 ‘대학생(학부생)’이 별개의 항목으로 안내되어 있다. 관람권은 전시별 조건이 있으며, 이번에는 특정 전시 예매나 발권을 확인하지 않았다.

| 데이터/상태 | 이번에 근거로 삼을 수 있는 내용 |
| --- | --- |
| 자료 유형 | 실제 공공기관 문화 혜택 안내. 정부 현금지원·학생 전용 전시·가상 장소 혜택으로 바꾸지 않음 |

| 연령 경로 | 현재 입력 만 나이 24세 이하 또는 65세 이상이면 공개된 연령 조건에 맞는 후보. 학생 여부는 이 경로의 필수 조건이 아님 |
| 학생 경로 | 공식 조건은 학부생이다. 기존 `student` 응답만으로 학부생 여부가 불명확하면 확인 필요. 대학원생까지 넓히거나 기존 값을 자동으로 학부생 인증으로 변환하지 않음 |
| 미입력 경로 | 나이·학생 여부가 미입력이라도 제외하지 않음. 나이 또는 학부생 여부 등 어떤 확인으로 후보가 될 수 있는지 안내 |
| 기간 | 종료일 없는 상시 관람 제도 안내. ‘상시 제도 안내 · 이용 조건 확인’이 적절하며, 오늘 모든 전시를 무료로 예약할 수 있다는 의미가 아님 |
| 남은 확인 | 해당 전시의 운영·관람 조건, 신분/학적 확인 방식, 실제 무료 발권. 학생증 이미지·학번을 이번 시연에서 수집하지 않음 |

학생 여부가 이 항목과 관련 있다는 점은 공식 본문으로 확인되었다. 다만 기존 저장값의 의미를 소급 변경하지 않고, 학부생 경로가 불명확하면 확인 필요 그룹에서 관련 이유를 표시한다. 연령 경로가 이미 맞는 사용자는 학생 여부 미입력 때문에 후보에서 제외하지 않는다.

- [창원문화재단 2026 SUPER! 수요콘서트 보도자료](https://www.cwcf.or.kr/commu/news_view.asp?BCATE=BD00002&BSUBCATE=&bidx=1505&idx=23644&page=3&skey=&sword=): 2026-09-03 본문에서 10월 28일 공연, 문화패스 30%의 7~23세 및 대학생 안내를 읽었다. 공연별 잔여석·학생 증빙을 확인하지 않았고 이번 일반 안내는 MMCA로 한정한다. 9월 30일 종료된 조기예매 할인은 현재 할인으로 쓰지 않는다.

- [국립국악원 공연 상세](https://www.gugak.go.kr/site/program/performance/detail?menuid=001001001&performance_id=36055): 검색 색인에 대학생 할인 조건이 있었지만 직접 열기는 시간 초과로 실패했다. 현재 공연 시기와 원문을 확보하지 못해 채택하지 않는다.

## 실제 수행 범위

공식 도메인 검색, 공개 URL 열기, 본문에서 기간·연령 방식·학부생·사용 지역과 거주 지역을 대조했다. 직접 읽은 본문과 검색 색인·오류 반환을 위에서 구분했다. 이 문서 작성은 출처 점검이며 앱 자동 검사나 브라우저 동작 검사를 대신하지 않는다.

회원 가입, 개인 신분·학적·주민등록 검증, 혜택 신청, 카드 발급, 예매·결제, 잔여 예산·재고 조회, 기관 연락은 수행하지 않았다. 현재 데이터는 확인일의 공개 안내 스냅샷이며 이후 자동 갱신 기능이 있다는 뜻이 아니다.
