# 11/5 멘토링 시연 안내

기준일: 2026-11-02. 브랜치 `feat/ai-recommend-field-reports`의 서울 펫 여행 MVP(명세 단계 0~6)를 시연한다. 구현·검사 기록은 [서울 펫 MVP 기록](../plans/15_SEOUL_PET_MVP.md), 실행·키 설정은 [팀 인수인계](TEAM_HANDOFF.md)를 본다.

위치 감지는 휴대폰에서만 되므로, **휴대폰 한 대로 처음부터 끝까지 진행하고 화면을 프로젝터로 띄우는 것**을 기본으로 한다. 노트북은 서버와 예비 화면이다.

## 시연 순서 (약 6~7분)

### ① 소개 — 홈 (30초)

- "차 없는 대학생 뚜벅이를 위한 서울 여행 앱. 여행 목적에 맞는 펫을 고르면 갈 만한 곳 3곳을 골라 준다."
- 펫 5종 = 여행 목적: 골든 활동, 시바 여유·힐링, 코기 맛집 탐방, 비숑 사진·감성, 백구 역사·문화.
- (2026-11-03 추가) 홈 위 장면은 지금 서울의 계절·기상청 실제 날씨·시간대로 그려진다. 오른쪽 위 칩을 눌러 눈·비·밤으로 바꿔 보여 줄 수 있고, 시연 뒤 "실제 계절·날씨·시간으로 돌아가기"를 누른다.

### ② 펫과 조건 → 추천 3곳 (1분 30초)

- (2026-11-04 D44) 추천은 이제 정한 곳 **근처를 실시간으로 검색**해 고른다. 같은 조건(**백구 → 경복궁역 → 4시간 → 2명 → 적당히**)이면 11/4 확인 때 경복궁(걸어서 약 6분)·서울시립미술관 서소문본관·서대문형무소역사관이 나왔지만, 실시간 자료라 당일 결과는 다를 수 있다. 시연 직전에 한 번 돌려 결과를 본다. 짚을 것: 위쪽 "종로구 사직동 근처", 카드의 "걸어서 약 N분"·카카오맵 걷기 길찾기·장소 사진("사진: 출처", 더 보기에도 모두), "팀 확인 전" 표시, **"지금 여유 · 경복궁 17:05" 같은 서울시 실시간 혼잡도**(붐비는 곳은 순위가 내려감), 아래 "지금 이 근처에서 하는 행사". 그 뒤 **추천 3곳 지도에서 보기** → 지도를 다른 동네로 밀고 **이 근처에서 추천 받기**를 누르면 그 동네로 다시 추천받는다(네이버 지도의 "이 지역 재검색"처럼).
- (참고, 근처 검색을 못 쓸 때) 카카오·TourAPI 키가 없거나 응답이 없으면 예전처럼 팀이 정리한 장소에서 고르고(최순우옛집·간송미술관·국립중앙박물관), 결과 위에 그 이유가 나온다.
- (2026-11-04) 조건은 한 화면에 질문 하나씩 나온다(D42). **경복궁역**을 누르면 저절로 시간 질문으로, **4시간**을 누르면 인원·걷기로 넘어간다. **+**로 2명을 만들고 **다음** → 확인 표를 보여 주고 **추천 받기**. 짚을 것: 펫이 질문마다 자기 말투로 묻고, 위쪽 칩을 누르면 그 질문으로 돌아간다. 확인 표에서 **바꾸기**(예: 시간 → 2시간)를 누르면 그 질문만 고치고 바로 확인 표로 돌아와 바뀐 줄이 빛난다. 시연 조건으로 되돌린 뒤(4시간) 추천 받기를 누른다. "현재 위치 사용하기"는 이제 펫 화면이 아니라 출발 위치 질문에 있다.
- 결과 카드에서 짚을 것: 펫 말투의 추천 이유, 가는 법, 현장 소식, 동네 친구 힌트. (2026-11-04) 이동 시간은 카카오 대중교통 실제 값이다: 3곳 모두 3호선 → 4호선 경로로 약 29~30분, 환승 2회, 1,550원이고 "카카오맵 길찾기"로 바로 열린다. 출구·도보 안내는 상세의 "가는 방법"(공식 안내 기준)에 있다. 휴대폰 서버는 `.env`의 `KAKAO_REST_KEY`가 있는 상태로 다시 켜야 이 값이 나온다.
- 시간이 되면 카드 아래 **다른 곳 더 보기**로 목적에 맞는 나머지 장소도 보여 준다(규칙 순서, 10곳씩).
- 말할 것: "AI 키는 승인 절차 중이라 지금은 같은 순서(목적 → 이동 부담 → 현장 소식)의 규칙으로 고른 결과다. 키를 넣으면 같은 화면에 AI가 고른 3곳이 나온다."
- 최순우옛집은 4~11월 화~토만 연다. 11/5(목)은 운영 기간이다.

### ③ 살아 있는 지도 → 장소 깨우기 (1분 30초) ★

1. **추천 3곳 지도에서 보기** → 카카오맵에 1·2·3 번호, 나머지는 "깨워 줄 곳(z)". (2026-11-04) 근처 검색으로 찾은 곳은 현장 소식이 올라오기 전에는 공유 지도에 없다가, 소식을 남기면 지도에 올라온다. 깨우기는 경복궁처럼 팀 장소인 곳으로 하면 바로 보인다.
2. 추천 장소의 점을 눌러 상세 → **현장 소식 남기기**(예: 한산함).
3. 창을 닫고 **소식 새로 고침** → **"○○이 깨어났어요!"**와 말풍선.

짚을 것: 소식은 유효시간(붐빔·한산함 3시간)이 지나면 흐려지고, 48시간 넘게 소식이 없으면 다시 깨워 줄 곳이 된다. 소식을 남기면 기여 점수가 오른다.

### ④ 구 도착 → 동네 친구 → 도감 (2분) ★

1. 추천 결과 화면(또는 홈의 **동네 친구 도감** 칸)에서 **구 도착 알림 켜기** → 위치 허용 → 지금 있는 구의 동네 친구 배너. 2026-11-03부터 이 단추는 홈에 없다(D37).
2. **만나기** → 친구 인사·구 소개, 가까운 장소, 장소 검색, 최신 소식. (2026-11-04) "지금 ○○구에서 뜨는 곳"의 해시태그 탭(#지금 한산해요 등)도 보여 줄 수 있다. 시연 서버에 쌓인 만큼만 보이므로, 시연 직전에 현장 소식이나 추천을 몇 번 해 두지 않았다면 대부분 비어 있다(빈 탭은 그렇다고 안내한다).
3. **현장 질문**에 답한다. 답은 현장 소식으로 공유된다고 화면에 안내된다. 500m 안에 후보지가 없으면 "인사하고 도감에 등록"이 나온다.
4. **동네 친구 도감 보기** → 3D 서울 보드에서 그 구가 솟아오르고 1/25. 보드를 옆으로 밀어 돌려 보인다. 아래 목록에서 못 만난 친구도 눌러 성격·말버릇·아는 친구를 보여 줄 수 있다(시연용 미리 보기, D47). 음표등↔선율지처럼 서로 언급하는 친구를 이어서 열면 좋다.
5. **이 구를 지도에서 보기** → "나" 위치와 근처 장소.

### ⑤ 마무리 (30초)

남은 것: AI 연결(키 승인 대기), 동네 친구 25종의 최종 이름·그림, 나머지 장소의 교통 정보 확인(시연 시나리오 25곳 중 17곳 확인 완료).

### 당일 30분 전

1. 노트북을 **휴대폰 핫스팟**에 연결하고, Windows 설정 → Wi-Fi → 그 네트워크 속성에서 네트워크 프로필 유형을 **개인**으로 바꾼다. 공용이면 방화벽이 휴대폰 접속을 막는다.
2. 서버를 켠다. 핫스팟 주소가 바뀌었을 수 있으니 인증서부터 새로 만든다.

   ```text
   node scripts/make-cert.mjs
   node scripts/serve.mjs --lan
   ```

3. 실행 화면의 `https://<노트북 주소>:4443`이 카카오 개발자 사이트의 JavaScript SDK 도메인에 없으면 추가한다(2026-11-02 등록: `http://localhost:4173`, `http://localhost:4183`, `https://10.155.128.90:4443`). 없으면 지도 대신 목록이 나온다.
4. 휴대폰에서 `?code=…`가 붙은 주소를 열고 인증서 경고를 넘긴다(Android '고급 → 계속', iPhone '세부사항 보기 → 이 웹 사이트 방문'). 위치는 **정확한 위치**로 허용한다. 접속 코드는 서버를 켤 때마다 바뀐다.
5. 시험 때 만난 동네 친구가 시연 장소 구의 친구와 같으면 "다시 만났어요"로 나와 현장 질문이 뜨지 않는다. 필요하면 휴대폰 브라우저에서 이 사이트의 데이터를 지우고 코드 주소를 다시 연다.
6. 지도 열기와 구 도착 알림(도감 화면)을 한 번씩 눌러 확인하고, 시연 직전에 알림을 끈다.
7. 휴대폰 배터리를 충전하고 방해 금지 모드, 화면 꺼짐 시간 연장을 켠다.

## 시연 후

- 서버는 `Ctrl+C`로 끈다.
- 시연 중 남긴 현장 소식은 `data/runtime/reports.json`에 있다(Git 제외). 지우려면 이 파일을 삭제한다.

## 확인하지 않은 것

- 걸어서 구 경계를 넘을 때 친구가 바뀌어 나타나는지(실제 이동 시험 전).
- 시연 장소에서의 위치 정확도와 휴대폰 핫스팟 연결.
- 홍대 걷고싶은거리·서리풀공원 몽마르뜨공원의 출구 안내(공식 출처 없음). 이 둘이 나오는 시나리오(2·8번)는 시연에서 피한다.
