작성 기준: 2026-10-24 (Asia/Seoul). 이 폴더는 클로드와 클로드 디자인에 사용자가 직접 전달할 작업 자료다. 서비스의 운영 스택·AI 모델·최종 디자인을 확정하거나 외부 서비스에 업로드한 결과물이 아니다. 기존 전달 패키지의 사본이 아니라 현재 사용자 결정과 로컬 시연을 정리한 새 문서다.

## 바로 전달하는 방법

문서와 시연 화면을 함께 전달하려면 [통합 ZIP](../Growing_Travel_Claude_Design_2026-10-24.zip)을 사용한다. 압축을 푼 뒤 `00_START_HERE.md`에서 대상별 첨부 목록을 확인하고, 각 폴더의 `PASTE_THIS_REQUEST.txt` 전체를 붙여 넣는다. [압축 전 동일 안내](../claude-delivery-2026-10-24/00_START_HERE.md)도 열 수 있다.

| 대상 | 첨부할 파일 | 함께 붙여 넣을 요청문 |
| --- | --- | --- |
| 클로드: 제품 검토·개발 설계 | [제품·개발 전달서](PRODUCT_AND_DEVELOPMENT_BRIEF.md) | [요청문 모음](PROMPTS.md)의 ‘클로드에 보낼 요청문’ 전체 |

각 전달서는 단독으로 읽을 수 있게 작성했다. 더 자세한 구현을 검토하게 하려면 두 전달서를 함께 첨부하고, 필요할 때 프로젝트의 docs와 dist 파일을 추가한다. 현재 검사 범위가 필요하면 [이번 작업 기록](../../plans/07_PERSONALIZED_BENEFITS.md)을 함께 전달한다. 로컬 파일의 상대 경로는 외부 도구에서 열리지 않을 수 있으므로 필요한 문서 자체를 첨부한다.

화면 참고는 [직전 모바일 추천 화면](../../plans/05_MOBILE_APP.png), [직전 혜택 탭](../../plans/06_BENEFITS_TAB.png)이다. 두 이미지는 과거 로컬 시연이며 새로운 맞춤 혜택의 최종 화면이나 확정 디자인이 아니다. 화면 참고 이미지를 전달할 경우 이 설명을 함께 붙인다.

이번 기능 참고는 [맞는 후보 화면](../../plans/07_PERSONALIZED_BENEFITS.png)과 [추가 확인 화면](../../plans/07_BENEFITS_NEEDS_INFO.png)이다. 390×844 브라우저 뷰포트에서 가상 입력(만 23세·거주지/대학생 여부 미입력)으로 확인한 화면이다. 실제 사용자 정보나 최종 디자인 승인 자료가 아니다. 자동 검사 72개와 브라우저에서 수행한 구체적 검사는 위 작업 기록에 남겼다.

## 디자인 작업 이후 추가된 자료

2026-10-26에 디자인 캔버스에서 진행한 결과를 [디자인 개발 전달](DESIGN_HANDOFF_2026-10-26.md)로 정리했다. 화면별 데이터·상태·이벤트·접근성 주석, 미확정 질문, 사용한 실제·가상 자료 목록이 들어 있다. 결정 장부의 D16·D17을 반영한 디자인 제안이며 구현 완료나 실기기 검사 결과가 아니다.

이후 사용자 요청 D18에 따라 위 전달서를 기존 로컬 시연에 반영했다. 문서 원문은 보존하고 세부 구현 선택과 이번 실제 검사 범위는 [디자인 구현 기록](../../plans/09_DESIGN_IMPLEMENTATION.md)에 남겼다. 최종 코드 자동 검사 78개 통과와 전용 로컬 브라우저의 조건·저장·입력 보존 사례를 확인했으며 실제 휴대폰·화면 낭독기 등 미실행 범위는 별도로 남긴다. 비공개 캔버스의 원본·픽셀은 확보하지 않았으므로 문서 기준 구성과 픽셀 일치 검증은 구분한다. 이전 ZIP과 화면 PNG는 당시 전달 이력이며 새 화면의 검사 증거가 아니다.

## 자료의 우선순위

1. 사용자의 현재 직접 지시와 전달서의 ‘사용자 결정’이 최우선이다.
2. 구현 선택과 디자인 제안은 변경 가능하지만 변경 이유와 영향 범위를 기록한다.
3. 미확정 사항은 질문·가정으로 표시한다. 모델·네이티브 기술·운영 지역·실제 후기·자격 인증을 임의로 확정하지 않는다.
4. 출처 확인일 이후의 혜택 운영 상태는 다시 확인한다. 디자인 예시의 가상 인물·혜택은 실제 사용자·실제 지원 사업으로 바꾸지 않는다.

문서에는 실제 사용자 개인정보·계정·인증정보·브라우저 저장 자료를 넣지 않았다. 개인정보를 외부 도구에 붙이지 않아도 흐름을 설계할 수 있도록 가상 입력 예시를 제공했다. 이번 작업은 문서 준비까지이며 클로드에 실제로 전송하거나 메시지를 보내지 않았다.
