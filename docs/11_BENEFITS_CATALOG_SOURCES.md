## 기간·자격을 표시하는 원칙

- 신청·발급 기간과 이용 기간을 분리한다. 날짜가 범위 안에 있으면 ‘공고 기간 중’으로 표시할 수 있지만 ‘오늘 신청 가능’이나 ‘지원 확정’으로 표현하지 않는다.
- 기간이 지나면 종료, 시작 전이면 예정, 날짜 근거가 없거나 자료가 오래되면 확인 필요로 표시한다. 저장된 확인일 이후의 자동 수집·실시간 재검증은 이번 구현 범위에 포함되지 않는다.
- 대학생 여부는 선택적으로 입력하는 자기 신고다. 대학명·학번·증빙을 수집하거나 자동 인증하지 않는다. 연령 대상 혜택을 대학생 전용 혜택으로 바꾸지 않는다.
- 혜택 탭의 공식 자료는 가상 지역 비교에 사용하는 가상 혜택과 별개다. 가입·신청·구매·예약·결제·지원금 계산은 수행하지 않는다.

## 확인한 작업과 미확인 범위

공식 도메인 검색, 위 링크 직접 열기, 공고의 신청/사용 기간과 게시일 대조를 수행했다. 숙박 행사·문화패스 정책브리핑·K-패스·인천교통공사 FAQ의 해당 본문을 읽었다. 코레일 직접 원문은 오류여서 공식 검색 색인 수준만 확인했다. 문화패스 현재 지역별 잔여 목록, 숙박 참여사별 재고, 개인 자격 및 실제 결제 적용은 확인하지 않았다. 비공식 블로그의 잔여 지역 목록을 확정 사실로 옮기지 않았다.

이 문서의 내용은 데이터 출처 점검 기록이다. 앱 동작·저장 호환·날짜 경계 검사는 구현 후 별도 기록한다. 외부 사이트에 가입하거나 신청서를 제출하지 않았다.
