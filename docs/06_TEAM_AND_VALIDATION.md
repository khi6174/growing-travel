# 06. 팀과 검증 운영

상태: CODEX_START와 PDF S05를 반영한 기준 초안. 별도 전달 패키지 docs 원문 미확보. 아래 역할·방법은 구현 제안이며 실제 팀 구성, 수행 인원, 인터뷰, 방문 검증, 성과를 뜻하지 않는다. 관련 미확정은 [결정 장부](00_DECISIONS_AND_SOURCES.md)의 Q05~Q09다.

## 필요한 역할 제안

| 역할 | 책임과 산출물 | 현재 배정 |
| --- | --- | --- |
| 제품 결정 | 대상 상황·우선 범위·미확정 선택 승인, D/P/Q 변경 근거 기록 | 미정 |
| 경험·출처 관리 | 실제 자료 확보·이용 허락·확인 범위·갱신 이력 | 미정 |
| UX·개발 | 첫 흐름 연결, 접근성·오류 복구·저장·권한 구현 | 미정 |
| 검증 | AC별 실제 실행 기록, 가상/실제 자료 구분, 결함 재현과 재검사 | 미정 |

한 사람이 여러 역할을 맡을 수 있다. 인원·직함·일정·외부 협력사를 지어내지 않는다. 현재 구현 팀이나 실사용자가 확보됐다는 근거는 없다.

## 증거 수준

| 자료/활동 | 확인할 수 있는 것 | 확인했다고 보고할 수 없는 것 |
| --- | --- | --- |
| 문서 정적 검사 | 로컬 참조 존재, 정의된 식별자, 출처 사본 무결성 | 앱 동작·추천 품질·원문 미확보 문서와의 일치 |
| 가상 데이터 시연 | 구현된 입력·추천 표시·저장 흐름 | 실제 장소 존재·영업·방문·실사용 만족 |
| 출처가 있는 실제 경험 자료 | 출처가 뒷받침하는 특정 사실 | 모든 내용의 진실성·현재 영업·미래 방문 만족 |
| 사용자 방문 진술 | 작성자가 방문했다고 진술했다는 사실 | 독립적으로 확인된 방문·검증된 후기 |
| 실제 사용자 관찰 | 참여 동의와 기록 범위 안의 사용 행동·진술 | 전체 시장 적합성·확보하지 않은 모집단 성과 |

## 이후 검증 계획 제안

먼저 AC01~AC08로 흐름을 검증한다. 이후 실제 경험 자료를 사용할 때 출처·확인 시점·허용 범위를 확보한다. 사용자 관찰에서는 상황 입력의 이해도, 추천 이유를 이해하는지, 불확실한 정보를 구분하는지, 코스 저장에 성공하는지를 본다. 기록·공개 단계에서는 비공개 기본값과 선택적 동의를 이해하는지도 확인한다.

참여자 수·성공률·만족도 목표는 정하지 않았다(Q09). 모집·외부 연락·현장 방문·인터뷰·대회 제출은 이번에 수행하지 않았다. 가상 후기나 가상 참여자를 검증 결과로 채우지 않는다(D07).

PDF 9쪽의 경험 카드 30개·여행자 10명은 제안 수치이며 확보한 자료·참여자·사용자 승인 목표가 아니다. PDF 10쪽의 검증 질문은 새로운 선택을 발견했는지, 현장에서 추천 이유가 맞았는지, 쉽게 기록하고 다시 썼는지다. 집단 경험의 확대와 개인 맞춤 개선을 별도로 관찰하는 방향을 반영한다. 공공 관광정보·팀 직접 확인·사용자 경험·가상 예시는 구분하며 공공 정보를 사용자 후기로 바꾸지 않는다(P13).

공동 일정 편집·기록 내보내기 유료화, 제휴 수수료 공개는 PDF의 수익 제안으로만 남긴다. 가격·지불 의사·도입 기능을 확정하지 않고 첫 구현에 넣지 않는다(Q09).

## 결과 기록 형식

향후 검증마다 날짜, 담당 역할/실제 수행자, 대상 버전, 데이터 유형, 적용 AC, 절차, 실제 관찰, 증거 위치, 제한 사항, 다음 조치를 기록하는 것을 제안한다. 개인정보는 목적에 필요한 범위만 남기고 보관·삭제 방식은 Q07에서 결정한다.

현재 실제 수행 증거는 [파일 정리 결과](../plans/01_FILE_SETUP.md)에 요약하고 PDF·외부 링크 상세 결과는 [원문 검토 기록](07_SOURCE_REVIEW.md)에 기록한다. [완료 기준](05_ACCEPTANCE_TESTS.md)의 시나리오는 실행 계획이며 결과가 아니다.

D12 개인 설정·여행 조건 확장의 구현·검사 증거는 [확장 기록](../plans/04_PROFILE_TRIP_DEMO.md)에 분리한다. 가상 혜택 조건을 비교한 결과는 실제 자격 심사·발급·할인 성과가 아니며, 공식 안내 링크를 제공했다는 이유만으로 최신 신청 상태를 검증한 것으로 보고하지 않는다. 실제 후기·게시판은 후속 단계이고 운영 담당·갱신 주기·신고 처리·실제 사용자 모집은 미확정이다.
