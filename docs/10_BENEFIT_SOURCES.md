# 10. 여행 관련 혜택 출처와 확인 범위

확인일: 2026-10-24 (Asia/Seoul). D11의 교통·숙박·여행·문화 범위에 따른 초기 출처 조사. 별도 전달 패키지 docs 원문 미확보. 이 문서는 안내 후보 장부이며 신청 가능·수혜 확정·현재 판매를 보장하지 않는다. [타겟 개발 방향](09_TARGET_FOCUS.md)의 혜택 계약과 함께 사용한다.

숫자는 위 공식 자료를 확인한 범위에 한정한 조사 기록이다. 코레일 두 상품군은 검색 색인 확인과 직접 원문 확인 수준을 구분했다. D12 확장에서는 이 근거를 독립된 공식 혜택 안내에 사용하며, 가상 지역 혜택의 할인 데이터나 계산식에 넣지 않는다. 개인 나이·거주 입력만으로 공식 혜택 적용을 확정하지 않는다.

지역 비교 시연에 쓰는 교통·숙박·여행·문화 혜택 예시는 별도의 **가상 자료**다. 실제 사업명·공식 출처를 가상 지원 조건의 근거로 붙이지 않는다. 가상 후보·조건 불일치·확인 필요·기간 종료 상태는 UI와 계약 검증용이며 실제 정부 지원의 심사 결과가 아니다. 비교·저장·재열람에서도 두 자료 유형을 구분한다.

## 오래된 공고와 이후 변경 구분

청년문화예술패스의 [2026-02-10 한국문화예술위원회 최초 모집 공고](https://www.arko.or.kr/board/view/4053?bid=0&cid=1810469&sf_icon_category=)는 최초 신청 마감을 6월 30일로 안내한다. 이후 문체부 8월 26일 안내는 8월 추가 발급을 설명한다. 따라서 최초 마감일 하나만으로 현재 전체 사업을 종료 상태로 판단하지 않았고, 추가 발급 안내만으로 오늘 신청 가능하다고 판단하지도 않았다.

2027년 확대 계획 등 다음 연도의 발표를 2026년 현재 자격으로 적용하지 않는다. 혜택 연령의 계산 방식·출생연도 기준은 원문 그대로 확인하고 서비스의 20대 타겟 정의와 분리한다.

## 아직 확보하지 않은 범위

- **숙박·지역 여행 지원:** 범위에는 포함하지만 지금 접수 중인 구체적 사업을 검증해 등록하지 않았다. 현재 이용 가능한 지원이 전혀 없다는 뜻은 아니다.
- 실제 여행 지역이 정해지면 해당 지자체·공식 관광기관 공고의 신청/사용 기간, 거주 제한, 숙박/결제/인증 조건, 예산 소진 여부부터 확인한다.
- 카드사 상업 프로모션을 포함할지는 별도 선택이다. 정부 지원·운영기관 할인과 섞어 표시하지 않는다.

## 실제 수행과 미실행

공식 도메인 검색, 링크 열기, 공개 본문과 발표일 비교를 수행했다. K-패스·문체부·한국문화예술위원회 페이지의 해당 본문을 확인했다. 코레일 원문은 직접 열람이 제한되어 공식 검색 색인 수준만 확인했다. 비공식 블로그의 조건을 공식 확인 결과로 채택하지 않았다.

회원 가입·카드 신청·본인 인증·혜택 신청·구매·예약·유료 서비스 이용·외부 연락은 수행하지 않았다. 사용자 개인의 나이·거주지·등록 이력을 확인하지 않았으므로 개인 수혜 판정은 하지 않았다. 다음 갱신 시 현재 조건을 다시 확인해야 한다.
