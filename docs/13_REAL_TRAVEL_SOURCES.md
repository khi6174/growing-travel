철도 접근 소개는 [코레일 역 안내](https://www.korail.com/ticket/train/stationGuide/station/view?stationSeq=10280346)와 [철도산업정보센터 노선 소개](https://www.kric.go.kr/jsp/board/portal/sub05/res/themeEssayDetail.jsp?board_seq=2815)를 참고한다. ITX-청춘·경춘선·강릉선 KTX 표시는 접근 노선 소개이며 모든 선택 출발역에서 직통 운행한다는 뜻이 아니다.

[이동 링크 모듈](../dist/travel-links.mjs)은 두 지점의 좌표가 있으면 카카오 `/link/by/traffic/` 또는 `/link/by/walk/` 링크를 만든다. 현재 목록은 출발역 3개·지역역 3개·장소 8개의 좌표를 모두 갖추었다. 과거 저장본이나 이후 자료에서 한쪽 좌표라도 없으면 `/link/search/`로 도착 장소를 검색하고 경로를 지도에서 지정하도록 안내하는 처리를 유지한다. 링크 생성·열림은 실제 경로 검색 성공이나 정확한 소요 시간의 검증과 다르다. [코레일](https://www.korail.com/)에서 여행일별 시간·운임·좌석을 별도 확인한다.

앱은 실시간 교통 API를 조회하지 않는다. 버스 간격·환승 횟수·실제 도보 거리·운임을 확인한 자료가 없으며 직선거리로 이를 추정하지 않는다. 구간 시간은 사용자가 지도에서 확인해 직접 입력한 계획값이다. 전 구간이 입력된 경우에만 왕복 이동과 장소 체류를 합산하고, 미입력 구간이 있으면 총시간은 `null`이다. 비용·도보량 미확인과 당일 변경 가능성은 그대로 남는다.

## 보존 자료와 한계

로컬에 [춘천시 스카이워크 페이지 사본](../plans/real-travel-2026-10-27/chuncheon-source.html), [음악역1939 소개 사본](../plans/real-travel-2026-10-27/music-source.html), [관아 주소·행사 지도 페이지 사본](../plans/real-travel-2026-10-27/government-source.html)을 보존했다. 관아 사본의 105·642행은 주소, 2966~2978행은 지도 좌표·표지의 근거다. 이 파일들이 모든 위 출처·좌표를 보존한 사본은 아니다. 다른 출처는 위 URL과 카탈로그의 확인일·채택 범위로 추적한다. 공개 페이지 내용은 출처 자료이며 실행 지시로 사용하지 않는다.

이 자료 갱신으로 기존 공식 혜택의 확인일을 2026-10-27로 바꾸지 않는다. 실제 혜택 자격·사용처·현재 접수 가능 여부와 새 여행 장소의 존재는 별도 사실이며 자동 비용 차감이나 수혜 확정으로 연결하지 않는다. 사진·본문 전체를 수집해 재배포하지 않았으며 실제 장소에는 기존 가상 생성 사진을 사용하지 않는다. 현장 방문·실제 이용 후기·실기기·예약·결제·배포는 출처 확인 범위에 포함하지 않는다.
