# 05. 완료 기준과 검증 시나리오

상태: CODEX_START와 PDF S05 및 D12 확장을 반영한 기준. 별도 전달 패키지 docs 원문 미확보. 2026-10-24 전체 자동 검사 41개를 통과했고 실제 로컬 브라우저에서 아래에 명시한 시나리오를 확인했다. AC02·AC04는 가상 시연 범위 통과이며 AC01~AC08의 나머지는 미확인 분기를 남긴 부분 검증이다. 후속 AC09~AC13은 미실행이다. [확장 검사 기록](../plans/04_PROFILE_TRIP_DEMO.md), [최초 로컬 검사 기록](../plans/03_LOCAL_DEMO_IMPLEMENTATION.md), [파일 정리 결과](../plans/01_FILE_SETUP.md)를 구분한다.

## 증거와 판정 방식

2026-10-26 D19의 2차 화면 근거는 [2차 디자인 구현·검사 기록](../plans/10_DESIGN_SECOND_PASS.md)에 분리했다. 전체 자동 검사 83개와 변경 모듈 구문 검사를 통과했고, 전용 390×844 인앱 브라우저에서 조건 3칸·메타/이유·티켓 장식·입력 속성·활성 오류 제출·초점·저장/재열람·현재 설정 보존을 확인했다. 오류 때 버튼을 비활성으로 막았던 1차와 달리 나이 230에서 두 제출 버튼이 켜져 있고 누르면 첫 오류 필드로 초점·범위 안내가 연결됨을 확인했다. 실제 휴대폰·화면 낭독기·안전 영역 모의·동작 줄이기 환경 전환·저장 실패 UI 주입은 검사하지 않았으며 기존 미실행 분기와 후속 AC09~AC13 상태를 유지한다.

2026-10-26 D18의 새 화면에 대한 추가 근거는 [디자인 구현·검사 기록](../plans/09_DESIGN_IMPLEMENTATION.md)에 분리했다. 최종 코드 전체 자동 검사 78개, 변경 모듈 2개 구문 검사, 전용 로컬 인앱 브라우저에서 조건 시트·필터·초점 순환·여행 단계·순서 변경·저장·새로고침·재열람·현재 개인 기준과 과거 코스의 분리를 확인했다. 혜택 폭 360/390/430px와 코스 390px를 검사했다. 이 결과는 실제 휴대폰·화면 낭독기·브라우저 완전 재시작·다중 탭/저장 실패 UI 주입 또는 후속 AC09~AC13의 통과를 뜻하지 않는다. 위 표는 범위 밖 분기의 미실행을 유지한다.

D12 확장에 필요한 개인 설정 선택 입력·저장 실패·삭제, 여행일/예산/인원 검증, 지역·혜택 비교, 조건 변경, 가상/공식 구분, 기존 저장본 재열람 검사는 [개인 설정·여행 조건 확장 체크리스트](../plans/04_PROFILE_TRIP_DEMO.md)에 별도로 기록한다. 위 AC 상태는 실제 추가 실행 증거가 있는 항목만 갱신했다. 최초 D09 검사 이력은 이전 기록에 보존하며 실제 후기·게시판은 다음 단계로 남는다.

구현 이후 실행 날짜, 대상 버전, 환경, 데이터 유형, 절차/명령, 기대·실제 결과, 증거 위치, 한계를 남긴다. 실패를 수정하면 해당 시나리오를 재실행한 결과를 남긴다. 실제 기록 전에는 위 상태를 변경하지 않는다.

첫 구현 완료 제안은 AC01~AC08 중 선택한 구현 범위에 적용되는 모든 검사의 실제 통과와 재열람 증거다. AC08의 계정형 전용 검사는 Q04에서 단일 사용자 로컬 저장을 선택한 경우에만 해당 없음으로 기록하며, 접근 제어 통과로 계산하지 않는다. 계정형을 선택하고 실행하지 않았다면 미실행이며 완료 조건을 충족하지 않는다. 로컬 가상 시연은 그 범위에서만 완료라고 표현한다. 실제 추천 품질·실제 장소 확인·보안 운영·다중 사용자 서비스·외부 AI 연동 완료를 자동 포함하지 않는다.

문서 참조 검사는 파일 간 경로와 식별자 연결을 확인할 뿐, 제품이 구현됐거나 출처 내용이 사실임을 증명하지 않는다. [제품 명세](01_PRODUCT_SPEC.md), [화면 흐름](02_UX_FLOWS.md), [계약](03_DATA_AND_AI_CONTRACT.md), [개발 순서](04_DEVELOPMENT_PLAN.md)와 함께 유지한다.
