# Growing Travel

**여행할수록 함께 자라는 AI 여행 추천**

경험 발견 → 상황에 맞는 추천 → 짧은 코스 구성·수정 → 개인 여행 기록 → 선택적 공개·방문 후 확인 → 다음 추천 반영.

2026-10-27 D23에 따라 **승인한 여행자 와이어프레임의 디자인을 기존 MVP `dist/`에 적용했다**. 여행 시작·내 설정을 포함한 9개 화면 흐름, 하단 4개 탐색, 주요 버튼과 동선 편집을 연결했고 혜택 쿠폰 형태를 유지했다(P27). 기존 추천·혜택 판정·명시적 저장·과거 코스 계약을 보존했다. 이번 전체 자동 검사 85개와 후속 지역 표시 변경 관련 22개 검사가 통과했으며, 실제 브라우저에서 저장·새로고침·재열람과 390/1440px 화면을 확인했다. 문서 정적 검사·독립 시각 검토를 포함한 최종 상태와 한계는 [와이어프레임의 MVP 적용 기록](plans/12_WIREFRAME_TO_MVP.md)에 별도로 남긴다.

직전 D22에서는 **여행자가 사용하는 Growing Travel 주요 화면 와이어프레임**을 만들었다. [여행 서비스 화면·실행 안내](wireframes/traveler-service/README.md)에서 홈·개인 설정·여행 조건·지역 비교·경험 추천·코스·혜택·저장·내 설정의 9개 모바일 화면을 검토한다(P26). D20의 동선 중심 구성과 혜택 쿠폰 방향을 적용한 별도 메모리 시연이며, 당시에는 기존 여행 MVP `dist/`와 저장 자료를 변경하지 않았다. 화면 보드와 앱 모드의 실제 확인 범위는 [와이어프레임 검사 기록](wireframes/traveler-service/QA.md)에 보존한다.
후속 D22는 이전 MCP 운영자 콘솔이 여행 서비스 주요 화면이 아니라는 사용자 정정을 반영한다. 해당 범위 해석은 잘못되었으며 D21/P25의 산출물과 검사 기록은 과거 이력으로만 보존한다. 현재 대상은 여행자용 [주요 화면 와이어프레임](wireframes/traveler-service/README.md)이다. P26에서는 D20의 동선 중심 구성과 혜택 쿠폰 방향을 이어 홈·개인 설정·여행 조건·지역 비교·경험 추천·코스·혜택·저장·내 설정의 9개 모바일 화면을 별도 HTML 메모리 시연으로 구성한다. 기본 화면 보드와 앱 모드에서 정보 구조·주요 행동 배치를 검토하며, 처음부터 혜택을 독립적으로 열 수 있게 한다. 세부 화면 수·소비자용 상세·조건 수정 시트는 구현 선택이며 새로운 사용자 승인으로 간주하지 않는다. 기존 여행 MVP `dist/`·도메인·저장 키·과거 저장본은 변경하지 않는다. 가상 동선·경험을 실제 자료로 표시하지 않으며 실제 후기·공개·예약·결제·실시간 경로 연동·외부 서비스 연결·영속 저장·배포는 범위 밖이다. 시연의 저장은 현재 실행의 메모리에만 남고 새로고침하면 초기화된다. 실행은 `node wireframes/traveler-service/serve.mjs`(4181 포트), 설계는 [DESIGN.md](wireframes/traveler-service/DESIGN.md), 실제 수행한 검사와 한계는 [QA.md](wireframes/traveler-service/QA.md)에 별도로 기록한다.

후속 D23은 위 여행자용 와이어프레임의 방향을 승인하고 기존 MVP `dist/`에 디자인을 적용하도록 요청한 것이다. P27에서 여행 시작·내 설정을 포함한 9개 화면, 동선 중심 코스·혜택 전용 쿠폰, 하단 4개 탐색과 화면별 주요 버튼·이동을 기존 기능에 병합했다. 취향과 내 설정은 기존 개인 설정 폼을 공유하고, 주요 행동은 하단 탐색 위에서 제공한다. D22/P26의 메모리 전용 시연과 달리 기존 MVP의 명시적 localStorage 저장·키·과거 코스 스냅샷을 유지한다. 화면 이동으로 설정·코스를 자동 저장하거나 현재 설정으로 과거 저장본을 덮어쓰지 않는다. 기존 공식 혜택 조건·기간·자료 확인일·미확인 사항은 디자인 작업 중 다시 확인한 것으로 바꾸지 않는다. 기존 역·정원·서가의 생성 가상 자산을 재사용했고 이번에 새 imagegen 이미지를 생성하지 않았다. 이번 변경·85개 자동 검사와 후속 관련 검사·브라우저 확인 및 미실행 범위는 [와이어프레임의 MVP 적용 기록](plans/12_WIREFRAME_TO_MVP.md)에 별도로 남긴다. 배포·유료 가입·Git 커밋/푸시·외부 예약/결제 연동은 수행하지 않는다.
# 여행자 와이어프레임의 기존 MVP 적용

기준일: 2026-10-27 (Asia/Seoul). 사용자 승인 D23, 구현 선택 P27. 상태: 기존 MVP 병합·아래 자동 검사·실제 브라우저 확인을 수행했다. 최종 문서 정적 검사와 독립 시각 검토는 결과 갱신 대기다. 이전 시연의 83개 검사나 와이어프레임 검사를 이번 MVP 검사의 통과로 재사용하지 않았다. 작업 폴더는 Git 저장소가 아니므로 Git 차이 검사를 수행했다고 보고하지 않는다.

## 요청과 기준

사용자는 [여행자용 와이어프레임](../wireframes/traveler-service/README.md)을 승인하고 기존 MVP에 적용하도록 요청했다. 동선 중심 구성과 혜택 쿠폰 형태를 유지하면서 주요 버튼 배치와 화면 이동을 연결하는 작업이다. [와이어프레임 설계](../wireframes/traveler-service/DESIGN.md)의 9개 화면 개념을 참고하되 실제 기존 추천·입력 단위·검증·저장 계약을 우선한다. 구체적인 DOM 공유·탐색 구현·여백과 크기는 P27의 구현 선택이다.

대상은 20대 혼자·무차량·기차/대중교통·도보 여행자다. 여행 시작 → 취향·개인 조건 → 이번 여행 조건 → 지역 비교 → 경험 선택 → 동선 편집·저장으로 이어지고, 혜택·저장한 코스·내 설정은 하단 탐색에서 접근한다. 혜택은 여행 입력 완료를 요구하지 않는다.

## 병합 범위와 보존 조건

| 영역 | 적용 방향 | 보존 조건 |
| --- | --- | --- |
| 화면 구조·주 행동 | 승인한 흐름에 맞춰 한 단계의 목적과 주요 버튼을 분명히 표시 | 기존 입력·오류·추천 근거·고급 필터를 기능 없이 숨기지 않음 |
| 여행 코스 | 역·이동 구간·경험·복귀를 연속된 세로 동선에서 읽고 수정 | 현재 스냅샷의 가상 계산값과 `null` 미확인 보존. 임의 시간·금액 복사 금지 |
| 혜택 | 개인 조건과 공고 상태를 분리하는 쿠폰 형태, 조건 수정·공식 근거 진입 | 실제 자료와 가상 지역 혜택 구분, 공식 조건·기간·확인일 유지, 비용 자동 차감 없음 |
| 주요 탐색 | 여행·혜택·저장한 코스·내 설정, 이전/다음 동작과 초안 유지 | 화면 이동을 명시적 저장으로 취급하지 않음 |
| 저장·재열람 | 기존 MVP의 이 브라우저 저장과 과거 코스 열기 | `growing-travel.local-profile.v1`, `growing-travel.local-demo.v1`, 버전/중복 요청·충돌·스냅샷 계약 유지 |
| 이미지 | 기존 역·정원·서가 생성 자산을 재사용 | 생성 가상 자료 표지 유지. 이번에 새 imagegen 이미지를 생성하지 않음 |

P26의 별도 와이어프레임은 참고·검토 자료로 보존한다. 그곳의 새로고침 초기화·예시 저장 코스·미연결 혜택 자리표시자를 기존 MVP에 복사하지 않는다. 기존 가상 지역·경험과 공식 혜택 목록을 계속 사용한다. 현재 개인 설정과 저장 당시 개인 조건은 별개이며, 학생 미입력은 비대학생이 아니다. 거주지는 여행 출발지와 구분한다.

위 수동 조작은 구현 담당이 실제 인앱 브라우저에서 수행한 결과이며 [런타임 확인 기록](design-2026-10-27/mvp-application/runtime-checks.json)에 모은다. 문서 담당은 자동 검사·코드 검토 기록과 캡처 파일 존재를 확인하여 반영했다. 표의 문서 정적 검사·독립 시각 검토는 아직 통과로 기록하지 않았다.

도구가 JPEG 바이트로 반환한 캡처는 픽셀을 수정하지 않고 PNG로 다시 인코딩했다. `.raw` 원본도 보존하며 [캡처 파일 정보](design-2026-10-27/mvp-application/capture-metadata.json)에 크기를 기록한다. CSS 뷰포트와 캡처 픽셀 크기는 Windows 브라우저 환경에 따라 다르므로 실기기 또는 픽셀 일치 검증으로 주장하지 않는다. 기존 취향·코스·혜택의 적용 전 캡처도 같은 폴더의 `before` 파일로 보존했다.

검사 주소 4177의 QA 중 만든 27세 개인 설정은 UI의 설정 지우기로 원래 미입력 상태로 복구했다. 저장 코스는 기존 1개와 이번 확인용 1개가 남는다. 표준 4173은 다른 출처의 저장소이며 자동 이동하지 않는다. 사용자는 같은 브라우저·같은 주소에서 저장 자료를 다시 열 수 있다.

## 현재 한계

문서 정적 검사와 독립 시각 검토의 최종 결과를 추가해야 한다. 공식 혜택 원문 현재성·개인 수혜·교통·영업·안전은 다시 확인하지 않았다. 실제 경로 API·예약/결제·후기/게시판·개인 기록 공개·배포·유료 가입·Git 커밋/푸시는 이번 범위에 없다. 스마트폰 실기기·가상 키보드·화면 낭독기·다크 테마/동작 줄이기 환경·브라우저 완전 종료 후 재시작은 미실행이다. 저장 손상·용량 실패·다중 탭 충돌은 기존 계약의 자동 검사 범위와 구분하며 이번 모든 UI 오류 분기를 주입했다고 주장하지 않는다.
