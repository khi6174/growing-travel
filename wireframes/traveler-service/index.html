여행자 관점의 정보 구조

여행을 고르고, 내 코스로 보관하기

  1. 여행 시작·취향

    관심사와 편하게 걷는 양을 정해요. 나이·거주·대학생 여부는 선택 입력이에요.

  2. 이번 여행 조건

    출발역·날짜·왕복 가능 시간·예산을 정해요. 거주지는 출발역과 별개예요.

  3. 지역 비교·경험 선택

    어디로 갈지 비교한 다음, 하고 싶은 경험과 추천 이유를 살펴요.

  4. 코스 편집·저장

    역에서 시작해 돌아오는 동선을 읽고, 순서를 바꾸거나 경험을 뺀 뒤 저장해요.

언제든 열 수 있는 메뉴

혜택은 여행 입력 없이 살펴볼 수 있어요. 저장한 코스에서는 당시 조건을 다시 보고, 내 설정에서는 지금의 취향을 관리해요.

주요 버튼의 자리

입력 화면은 입력 아래, 비교 화면은 해당 후보 설명 다음, 경험·코스 화면은 하단 메뉴 위에 주 행동을 둡니다. 자세한 조건과 근거는 별도로 펼쳐 읽습니다.
