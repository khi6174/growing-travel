# MCP 연결·관리 와이어프레임

2026-10-27 사용자 요청 D21을 구체화한 P25 설계 제안이다. 함께 디자인한 Growing Travel MVP의 흑연·코발트, 모서리 위계와 주요 행동 배치 원칙을 활용해 운영자의 MCP 연결·관리 화면을 검토한다. 기존 여행자용 `dist/`와 분리되어 있으며 여행 기능·저장 자료는 그대로 유지한다.

## 실행

프로젝트 루트의 PowerShell에서 실행한다. 패키지 설치나 빌드는 필요 없다.

```powershell
node wireframes/mcp-management/serve.mjs
```

서버 시작 안내가 나오면 [와이어프레임 열기](http://127.0.0.1:4180)를 연다. 서버는 로컬 4180 포트를 사용하며 `Ctrl+C`로 종료한다. 포트 충돌이 나면 다른 프로그램을 임의로 종료하지 말고 해당 오류를 확인한다. 기존 여행 시연의 4173 포트와 별도다.

## 여섯 화면과 검토 방법

| 화면 | 검토할 핵심 행동 |
| --- | --- |
| 연결 개요 | 연결 상태·MVP 사용 위치를 비교하고 연결 추가 또는 상세로 이동 |
| 연결 추가 | 이름·주소를 입력하고 확인 결과 시연을 선택한 뒤 연결 확인·구성 저장 |
| 연결 상세 | 연결·인증·도구 발견 상태를 각각 확인하고 도구·접근 설정으로 이동 |
| 도구·접근 | 앱에서 사용할 도구를 선택하고 변경 저장 또는 초안 취소 |
| 활동 기록 | 연결·결과별 활동을 살펴보고 ‘오류 진단’으로 이동 |
| 연결 복구 | 문제의 실패 지점과 영향, 원인별 다음 행동을 읽고 복구 시연 |

검토용 화면 선택으로 여섯 화면을 비교하고, 제품 화면 안에서는 연결·활동의 두 전역 메뉴와 선택 연결의 하위 이동을 확인한다. 검토 주석은 화면 목표·정보 순서·주 행동 위치·예외를 설명한다. 정보 구조 팝업에서 화면 관계와 버튼 위치를 함께 살펴본다. 넓은 화면과 좁은 화면의 배치 기준은 [DESIGN.md](DESIGN.md)에 기록한다. 반원 홈은 혜택 정보가 MVP에 표시되는 미리보기에만 사용한다.

## 시뮬레이션 경계

입력·저장·도구 허용·연결 확인·복구·활동은 브라우저 메모리 안의 가상 동작이다. 결과 선택으로 성공·실패 상태를 검토하며 새로고침하면 초기 예시로 돌아간다. 연결 구성을 저장하는 행동과 서버 응답·인증·도구 발견·도구 실행 성공은 별도 상태로 읽는다. 앱 내부의 도구 허용 목록도 외부 서버의 인증 권한과 다르다.

실제 MCP 서버 연결·OAuth·권한 부여·호스트 설정 변경·영속 저장은 구현하지 않았다. 자격 증명을 입력하지 않는다. 예시 연결·도구·활동 기록은 운영 데이터나 실제 연결 결과가 아니다. 네트워크로 서버를 확인하거나 기존 여행자의 개인 설정·저장 코스를 읽지 않는다.

LazyCodex/OmO의 설치된 frontend 기준과 역할별 검토를 활용한다. 별도 `lazycodex-ai` 이름의 MCP 실행 도구가 제공되어 호출된 것으로 표현하지 않는다. 와이어프레임 제작과 MCP 실제 연결은 별개다.

## 근거와 검증

[공식 MCP 아키텍처](https://modelcontextprotocol.io/docs/2026-07-28/learn/architecture), [서버 개념](https://modelcontextprotocol.io/docs/2026-07-28/learn/server-concepts), [Authorization](https://modelcontextprotocol.io/specification/2026-07-28/basic/authorization)는 개념 참고 자료다. 이 프로젝트의 화면 배치·상태명·허용 목록 정책은 구현 제안이며 프로토콜의 필수 UI가 아니다.

사용자 결정과 구현 선택은 [결정·출처 장부](../../docs/00_DECISIONS_AND_SOURCES.md)의 S19·D21·P25, 화면 설계는 [DESIGN.md](DESIGN.md), 직접 실행한 검사·증거·남은 한계는 [QA.md](QA.md)에 구분한다. 기존 여행 MVP의 검사 결과나 실행 명령 안내를 새 와이어프레임 통과 근거로 사용하지 않는다.
