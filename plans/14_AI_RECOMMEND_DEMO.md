# AI 추천 흐름 시연 점검 (2026-10-30)

D26/S25의 "조건 입력 → AI 추천 → 상세 → 현장 제보" 흐름을 11/5 시연 시나리오로 처음부터 끝까지 돌린 기록이다. 결정과 구현 선택은 [결정 장부](../docs/00_DECISIONS_AND_SOURCES.md)의 D26, P29~P33을 따른다.

## 실행 환경

- 브랜치 `feat/ai-recommend-field-reports`, 커밋 전 작업 트리
- `node scripts/serve.mjs --port 4183`, Node v20.19.5, 앱 내장 브라우저 375×812 모바일 에뮬레이션
- **AI 키 없음**: `.env`가 없어 서버 시작 메시지가 `AI: anthropic not configured, rule ranking only`였다. 이번 실행의 추천은 모두 규칙 정렬이며 실제 AI 응답은 확인하지 않았다. AI 경로는 가짜 제공자를 쓰는 자동 검사([tests/recommend.test.mjs](../tests/recommend.test.mjs))로만 확인했다.

## 시연 전에 알고 있어야 할 점

- 같은 브라우저에서 두 번째 여행자를 보이려면 기여자 ID를 바꿔야 한다. 실제 시연에서는 두 기기(또는 다른 브라우저 프로필)로 보여주는 편이 자연스럽다. 서버가 `127.0.0.1`에만 열려 있어 휴대폰으로 접속하려면 별도 설정이 필요하다(미구현).
- 점검 후 고친 점(같은 날): 후보지 설명 29곳을 존댓말로 바꿈, 시간대 선택지 줄바꿈 방지(375px에서 "하루 종일" 한 줄 확인), 규칙 정렬 이동 요약을 `서울역 출발 → 장소 가까운 역 안내. 서울역에서 이 역까지는 지도 앱 길찾기로 확인해 주세요.`로 바꿔 빠진 구간을 지어내지 않고 드러냄(출발역이 이미 안내에 있으면 그대로 사용). 자동 검사 116개 통과.
- 점검 중 남긴 `[시연 테스트]` 제보와 기여자 ID는 정리했다.
