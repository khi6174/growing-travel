# 개인 설정·여행 조건 로컬 시연 확장

작성일: 2026-10-24 (Asia/Seoul). 근거: D12 사용자 승인, P18 구현자 선택. 별도 전달 패키지 docs 원문 미확보. 이 기록은 [최초 파일 정리](01_FILE_SETUP.md)와 [최초 로컬 구현·검사](03_LOCAL_DEMO_IMPLEMENTATION.md)를 보존한 후속 기록이다. 검증 결과는 실제 수행 증거만 기입한다.

## 승인된 범위

개인 설정 → 이번 여행 조건 → 지역·혜택 비교 → 지역 선택 → 경험 추천과 근거 확인 → 코스 편집·저장·재열람을 기존 로컬 시연에 연결한다. 실제 평점·후기 열람, 여행 후 기록·공개, 게시판은 다음 단계로 남긴다. 배포·유료 가입·Git 커밋·푸시·예약·결제는 수행하지 않는다.

개인 설정의 만 나이·거주 지역은 선택이다. 성별은 초기 입력에서 제외하며 거주 지역과 이번 여행 출발역을 구분한다. 혼자 1명이 기본이고 여행일·가능 시간·1인 예산·인원·도보 한도를 지역 비교 전에 입력한다. 혜택 우선 비교는 사용자가 선택한다.

이번 시연의 출발역은 가상2개, 거주 지역 선택은 시·도17종이다. 여행일은 과거 날짜도 허용해 가상 혜택의 기간 시작 전·기간 종료 상태를 확인할 수 있게 했다. 과거 날짜 입력이 실제 예약·현재 신청 가능을 의미하지 않는다.

## 점검과 변경 기준

- 기존 AGENTS·README·프로젝트 구조·코드를 확인했다. 현재 작업 공간은 Git 저장소가 아니므로 Git diff로 사용자 변경분을 구분할 수 없다. 기존 파일을 읽고 필요한 부분만 병합하며 원문 사본·과거 검사 기록을 보존한다.
- 최소 스택은 기존 HTML/CSS/브라우저 JavaScript 모듈·Node.js 로컬 서버·localStorage를 유지한다. 외부 AI·지도·혜택 API·계정 서버는 추가하지 않는다. 운영 스택·AI 모델 확정이 아니다.
- 개인 설정은 `growing-travel.local-profile.v1` 키에 명시적으로 저장·삭제한다. 코스는 기존 `growing-travel.local-demo.v1` 키를 유지하며 신규 코스의 선택적인 `journeySnapshot`으로 당시 입력·가상 지역 비교 정보를 보존한다. 확장 전 저장본에 이 필드가 없는 경우의 재열람·수정 자동 검사를 통과했다.
- 가상 온유동·가상 바람마을과 가상 역·동선·시간·가격·교통/숙박/여행/문화 혜택은 시연 자료다. 공식 혜택 안내는 별도이며 실제 지원이 가상 장소에 적용된다고 표시하지 않는다. 혜택을 비용에서 자동 차감하지 않는다.

### 실제 화면에서 확인한 경로

1. 나이·거주지를 비운 상태로 진행하고 인원 기본1명과 지역 비교를 확인했다. 온유동 경험2개로 만든 초안을 열어 추천 근거 대화상자를 확인했다.
2. 제목을 `시연 확인 · 온유동 하루`로 변경해 저장했다. 새로고침 후 저장 목록이 유지됐고 다시 열 수 있었다. 순서를 바꿔 버전2로 저장했다.
3. 개인 설정의 걷기 허용량75를 명시적으로 저장한 뒤 새로고침에서75가 복원되는 것을 확인했다. 이후60으로 다시 저장했다. 나이0 입력 오류와 이전 추천이 숨겨지는 상태도 확인했다.
4. 저장하지 않은 가상 입력24세·서울·걷기120으로 비교해 지역별 가상 혜택 후보2개/1개와 혜택 우선 정렬을 확인했다. 지역 변경 확인을 거쳐 바람 물길 추천·동선·80분 표시를 확인했다.
5. 공식 혜택 안내5개에서 출처·확인시점·본문 직접 확인/검색 색인 확인의 차이를 확인했다. 외부 공식 링크를 클릭하거나 신청 상태를 새로 검증하지는 않았다.
6. 마지막 새로고침으로 나이·거주 비입력과 걷기60 설정을 복원했다. 브라우저에는 위 제목의 가상 코스1개가 남아 있으며 실제 사용자 여행·방문 자료가 아니다.

### 발견한 문제와 수정 후 재검사

- 지역 비교에 포함된 도보 전용 경험이 기존 이동 필터 때문에 추천에서 빠지는 문제를 발견했다. 신규 코스에 `walk_transit` 통합 필터를 적용하고 기존 `any`·`walk`·`transit` 호환을 유지했다. 회귀 검사를 포함한 최종41개가 통과했다.
- 미확인 구간이 있더라도 이미 아는 최소 시간·도보량이 한도를 넘으면 `unmet`이어야 한다. 총합은 `null`로 남기면서 알려진 초과를 표시하도록 수정하고 검사했다.
- HTTP 검사는 처음 localhost 연결 권한 때문에 `EACCES`로 실패했다. 권한 승인 후 전체 검사를 재실행해 통과했다.
- 중간 검사에서 가상 자료 라벨의 문구 불일치가 발생했다. 원래 라벨을 복원한 뒤 최종 전체 검사에서 통과했다. 중간 실패를 처음부터 통과한 것으로 기록하지 않는다.

### 미실행과 범위 제한

개인 설정 삭제·저장소 오류·구형 저장본 호환은 자동 검사만 수행했다. 브라우저 완전 종료 후 재시작, 모바일 뷰포트·실기기, 실제 다중 탭 충돌·오류 주입, 실제 혜택 자격·신청·잔여 예산, 실제 교통편·후기·방문은 검증하지 않았다. 검사용 서버는 Ctrl+C 전달 후 프로세스 종료를 확인했다. 다시 보려면 프로젝트 폴더에서 `node scripts/serve.mjs`로 실행한다. 사용자 실행 명령은 README에도 유지한다. 원문 사본과 최초 plans/01·plans/03 기록은 보존했다.

## 남은 사항

실제 운영 지역·경로 자료·가격·혜택 모집 상태, 공식 혜택 갱신 담당·주기, 실제 후기의 확보·이용 허락, 계정·공개·신고 운영, 운영용 저장 방식과 AI 모델은 미확정이다. 이번 시연의 성공이 실제 여행 가능성·수혜 확정·실제 사용자 만족을 증명하지 않는다.
