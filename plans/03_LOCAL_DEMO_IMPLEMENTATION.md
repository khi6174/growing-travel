# 03. 로컬 최소 시연 구현과 실제 검사

작성일: 2026-10-24 (Asia/Seoul). 사용자 후속 요청 D09에 따라 상황 입력 → 경험 추천·근거 확인 → 코스 구성·저장·재열람을 로컬 시연으로 구현했다. 운영 서비스 전체나 AI 모델 연결의 완료를 뜻하지 않는다.

## 시작 상태와 보존

기존 AGENTS.md·README·docs/00~07·첫 과제·계약·완료 기준과 파일 목록을 확인했다. 기존 앱 코드는 없었고 Git 저장소도 아니었다. 기존 기획 문서와 원문 사본은 보존하고 현재 단계·결정·검사 상태만 필요한 범위에서 갱신했다. [최초 점검](01_FILE_SETUP.md)과 당시 검사 JSON은 역사 기록으로 유지했다.

## 이번 선택

HTML/CSS/브라우저 모듈과 이미 설치된 Node.js v24.14.0의 기본 기능을 사용해 패키지 설치·빌드를 생략했다. 화면에는 자체 기하학 일러스트를 사용하며 외부 이미지·폰트·스크립트를 요청하지 않는다. localStorage는 같은 프로필·같은 출처의 작은 저장 목록에 한정한다. Web Locks 미지원 시 저장을 거부해 동시 쓰기 안전성을 성공으로 위장하지 않는다.

실제 모델은 선택하지 않았다. 규칙 기반 엔진이 최대 4개 후보와 입력 조건·가상 근거를 연결한다. 실제 지역·방문·영업·이동·안전 정보가 아니다. 총 이동 시간은 미확인이며, 경고를 확인한 초안만 저장한다. 데이터는 서버로 전송하지 않는다.

## 실제 수행한 검사

| 검사 | 실제 결과 | 한계 |
| --- | --- | --- |
| `node --test tests/domain.test.mjs tests/storage.test.mjs` | 핵심 검사 20개 통과 | 저장소·잠금은 주입한 메모리 어댑터로 계약 검증. 실제 브라우저 엔진 검사는 아님 |
| `node --test tests/server.test.mjs` | HTTP 검사 1개 통과. HTML/CSS/모듈 응답, 비공개 작업 파일 경로 차단, POST 405, 허용 외 Host 403 | 로컬 루프백만 검사. 배포·운영 보안 인증 아님 |
| `node --check dist/app.mjs` 및 `node --check scripts/serve.mjs` | 종료 코드 0 | 구문 검사이며 DOM 동작·화면 완성도 검증 아님 |
| 별도 정적 코드 검토 | 재추천 대기 중 이전 카드·코스 편집이 가능하던 경쟁 상태를 찾아 비활성화 및 핸들러 가드로 수정 | 브라우저 재현·지연 UI 검증은 미실행 |
| 서버 실행 | `http://127.0.0.1:4173`에서 시작 로그 확인 | 공개 배포 아님. 사용자가 실행하려면 README 명령 사용 |
| 문서 정적 검사 | 종료 코드 0. Markdown 15개, 식별자 정의 66개, 원문 사본 2개 해시 일치. 최종 집계는 [현재 검사 JSON](03_DOC_CHECK_RESULTS.json) | 외부 링크·제품 UI·실제 장소를 검증하지 않음 |

검사 중 최초 HTTP 연결은 샌드박스 EACCES로 실행되지 않았다. 로컬 연결 권한으로 다시 실행했고, Host 위조 테스트는 fetch가 해당 헤더를 전달하지 않아 200을 받는 시험 코드 문제가 있어 기본 HTTP request로 바꿨다. 변경 후 HTTP 검사는 통과했다. 실패했던 시도를 성공으로 합산하지 않았다.

## 브라우저 확인의 한계

브라우저 도구의 초기 접근은 중단/시간 초과였다. 지원되는 Windows Computer Use로 전환했으나 새 탭 작업 시 현재 브라우저 URL을 정책 적용에 충분한 신뢰도로 확인하지 못해 도구가 이번 턴의 조작을 중단했다. 이후 브라우저 조작이나 우회 자동화를 수행하지 않았다.

따라서 실제 화면·반응형 배치·키보드 이동·근거 창·클릭 저장·새로고침·브라우저 재시작·실제 다중 탭 동시 저장은 **미실행**이다. 스크립트·데이터 계약 통과를 이 검사의 통과로 보고하지 않는다. AC01~AC08은 부분 검증이며 AC09~AC13은 미구현·미실행, 계정형 전용 검사는 이번 단일 사용자 시연에 해당 없음이다.

## 사용자가 재현할 화면 확인 절차

다음은 안내 절차이며 수행한 검사 결과가 아니다.

1. README대로 서버 실행 후 같은 Chrome/Edge 프로필에서 `http://127.0.0.1:4173`을 연다.
2. 기본 180분·산책과 자연·조용한 쉼으로 추천한다. 가상 표지, 근거 상세, 입력·근거 ID와 미확인 정보를 확인한다.
3. 두 경험을 담고 순서를 바꾼 뒤 이름을 수정한다. 미확인 경고를 체크하고 저장한다.
4. 저장한 코스 탭에서 다시 열어 순서·이름·가상 표지·당시 근거를 확인한다. 새로고침 후에도 확인한다.
5. 가능 시간을 1분으로 바꿔 0건, 0/음수 또는 관심 선택 해제로 필드 오류를 확인한다. 기존 코스가 있으면 새 추천의 교체 안내를 확인한다.
6. 같은 코스를 두 탭에서 열고 각각 다르게 수정하면 나중 저장은 버전 충돌을 표시해야 한다. 저장본을 새로 열기 전 현재 편집 내용을 별도로 확인한다.

## 범위 밖과 다음 단계

배포·유료 가입·외부 예약/결제·Git 커밋/푸시는 수행하지 않았다. 실제 장소·모델·개인정보를 사용하지 않았다. 우선 남은 화면 검사를 수행하고, 이후 개인 기록 → 선택적 공개·방문 후 확인 → 다음 추천 반영 순서로 확장한다. 운영 기술·계정·실데이터·AI 모델은 별도 결정이다.
