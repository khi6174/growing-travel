# 디자인 2차 전달 반영 · 로컬 시연 기록

작성 기준: 2026-10-26 (Asia/Seoul). 상태: 2차 디자인 반영, 최종 자동 검사 83개·변경 모듈 구문 검사·390px 브라우저 확인과 최종 문서 정적 검사 완료. [1차 기록](09_DESIGN_IMPLEMENTATION.md)의 78개 검사와 이전 PNG, 전달 폴더의 헤드리스 렌더 사진을 새 앱 동작 검사 증거로 재사용하지 않았다.

## 요청·출처·기존 상태

사용자가 [2차 시작 안내](../handoff/codex-design-2026-10-26/00_START_HERE.md)부터 읽고 [디자인 명세](../handoff/codex-design-2026-10-26/DESIGN_SPEC.md)·원본 HTML·화면 사진을 바탕으로 기존 `dist/`를 수정하도록 요청했다(S17). 1차 D18·P22 이후 달라진 사용자 승인 사항은 D19, 기존 앱에 병합하는 구체적인 선택은 P23으로 [결정 장부](../docs/00_DECISIONS_AND_SOURCES.md)에 구분한다. 최신 직접 요청의 접근성·오류 제출 조건도 구현 범위에 포함한다.

[작업 기준](../AGENTS.md)·[README](../README.md)·필수 기준 docs·[1차 기록](09_DESIGN_IMPLEMENTATION.md)을 확인했다. `git status --short`에서 현재 `C:\성장 여행 서비스`는 Git 저장소가 아님을 다시 확인했다. Git 기준 변경분 비교는 할 수 없으므로 기존 파일·사용자 제공 자료를 보존하고 필요한 부분만 병합한다.

제공된 `MANIFEST.json`의 47개 항목을 파일 바이트 수와 SHA-256으로 대조했다. 원본 HTML 23개, 화면 PNG 21개, 안내·명세·요청문 3개 모두 일치했고 누락·불일치 0개였다. 이 검사는 전달 자료의 무결성을 확인한 것이며 사진의 실기기 검증이나 앱 동작 통과를 뜻하지 않는다. 원본·화면·매니페스트는 수정하지 않는다.

화면 사진은 원본 HTML을 390px 기준 헤드리스 Edge에서 렌더링한 자료이며 실제 휴대폰 캡처나 캔버스 자체 캡처가 아니다. 명세를 우선해 구조·스타일을 구현하고 픽셀 일치를 목표로 하지 않는다. `sc-for`·`sc-if`·`{{ }}` 같은 원본 도구 문법을 앱에 복사하지 않는다.

색·글꼴은 기존 흑연·코발트와 로컬 대체 글꼴 방향을 유지한다. 혜택 판정·정렬·공식 자료 확인일과 저장 키·과거 코스 스냅샷·가상 자료 표시는 바꾸지 않는다. 공식 혜택은 가상 코스 비용에서 차감하지 않는다.

실제 변경 파일은 [화면 구조](../dist/index.html), [화면 동작](../dist/app.mjs), [스타일](../dist/styles.css), 새 [표현 모듈](../dist/ui-copy.mjs)과 [표현 검사](../tests/ui-copy.test.mjs)다. 표현 모듈은 메타 문구의 가운뎃점을 정리하고 고유 표기·경로 순서를 보존한다. 기존 카탈로그·혜택 판정·추천 도메인·저장 모듈은 수정하지 않았다.

1차 당시 오류 버튼 비활성 검사는 당시 이력으로 보존한다. 최신 요청에서는 오류 버튼을 활성으로 두되 검증 실패 시 저장·적용을 하지 않는 것으로 바뀐다. 분리된 시트 초안, 명시적 저장과 일시 적용 구분, 닫기·Esc·초점 복귀와 현재 설정/과거 코스의 분리는 유지한다. 세부 선택 이유는 [로컬 시연 결정](../docs/08_LOCAL_DEMO_DECISIONS.md)에 남긴다.

자동 검사 초기 샌드박스 실행은 80개 통과·로컬 서버 연결 `EACCES` 1개 실패였다. 이를 앱 통과로 처리하지 않았으며 허용된 환경에서 전체 81개 통과를 확인했다. 이때 새 표현 검사는 3개였다. 이후 메타 문장의 가운뎃점 처리 회귀 검사를 2개 더하고 최종 전체 검사를 실행해 **83개 통과, 실패·취소·건너뜀 0개, 종료 코드 0**을 확인했다. 최종 결과를 1차 78개 검사에서 가져오지 않았다.

앱 검사와 문서 정적 검사는 별개다. 사진에 보이는 가상 조건·코스 개수·가격을 실제 검사 결과로 바꾸지 않는다.

문서 초안 병합 뒤 1차 정적 검사는 Markdown 39개·로컬 참조 367개·정의 86개·수용 기준 13개, 실패 0개·종료 코드 0이었다. CODEX_START·PDF 사본의 SHA-256 일치도 확인했다. 이는 초안 시점의 문서 구조 검사이며 최종 앱 검사를 대신하지 않는다.

기록 마무리 뒤 최종 문서 검사도 실패 0개였다. [최종 문서 검사 결과](10_DOC_CHECK_RESULTS.json)에 실제 참조 수·출처 사본 일치·수용 기준별 범위를 보존했다. 전달 파일 47개의 바이트·SHA-256 재대조도 모두 일치했고 앱 HTML에 캔버스 전용 문법이 복사되지 않았음을 확인했다.

## 검사 정리와 사용자 페이지

전용 검사 서버 `4176`은 Ctrl+C로 종료했고 임시 390px 뷰포트를 초기화한 뒤 검사 탭을 닫았다. 사용자가 완료 후 페이지를 열어 달라고 직접 요청했으므로 기본 `4173` 서버를 사용자 확인용으로 실행해 [혜택 페이지](http://127.0.0.1:4173/#benefits)를 앱 브라우저에 열었다. 실제 열린 페이지의 새 조건 3칸·쉼표 메타와 기존 저장 코스 2개를 확인했고 페이지를 남겼다. 기존 `4173`에서 입력·설정 저장·코스 저장은 수행하지 않았다. 사용자 확인용 기본 서버는 페이지를 사용할 수 있도록 켜 두며 검사용 서버 종료와 구분한다.

## 남은 범위

추천 출력에 없는 경험별 제외 사유는 새로 만들지 않으며 1차 기록과 명세에 따라 후속 계약 검토로 둔다. 원본의 시간·걷기 3지선다, URL 상태·다크 모드·드래그 정렬·빼기 되돌리기·로딩 화면 같은 보류 제안을 승인된 기능으로 승격하지 않는다.

실제 휴대폰·가상 키보드·화면 낭독기·안전 영역 모의·OS 동작 줄이기 환경 전환, 저장 실패·손상의 실제 UI 주입은 미실행이다. 자동 저장 오류 검사가 실패 UI 검사를 대신하지 않는다. 혜택 원문 재조사·개인 수혜·예약/결제·외부 신청은 별도 범위다. 배포·유료 가입·Git 커밋·푸시·외부 전송은 수행하지 않았다.
