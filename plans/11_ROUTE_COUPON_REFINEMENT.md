# 동선 중심·혜택 쿠폰 디자인 고도화

기준일: 2026-10-27 (Asia/Seoul). 사용자 선택 D20, 구현 선택 P24. 기존 Git 저장소가 없는 작업 폴더에 필요한 부분을 병합했으며 이전 기록·제공 원본·저장 계약을 보존했다.

## 요청과 시각 자료

사용자가 Product Design으로 서비스 디자인 고도화를 요청하고 “1번을 토대로 잡고 3번의 쿠폰모양 틀을 활용하자.”고 선택했다. [동선 시안](design-2026-10-27/source-route.png)과 [쿠폰 시안](design-2026-10-27/source-coupon.png)을 참고해 [결합 시안](design-2026-10-27/source-combined.png)을 먼저 생성·표시한 뒤 기존 로컬 앱에 반영했다. 시안의 임의 시간·금액·시각과 새 제안을 사용자 결정으로 간주하지 않는다.

코스의 주 행동은 **코스 저장**, 정보 우선순위는 **역과 경험의 순서 → 가상 총시간·도보·비용 → 별도 혜택 확인**이다. 사진형 썸네일과 역 그림은 생성한 가상 이미지이며 실제 장소의 사진이나 방문 증거가 아니다. 실제 후기·평점·예약·결제는 추가하지 않았다.

Layout: 기존 모바일 단일 열과 하단 4개 탐색을 유지한다. 문서가 세로 스크롤을 소유하며 코스 화면은 제목·3칸 요약·편집 가능한 경로·별도 혜택 쿠폰·확인/저장 순서다. 혜택 화면의 분야 필터는 가로 스크롤, 조건 수정 시트는 모달 내부 스크롤이다. 코스 전체의 티켓화, 같은 동선의 이중 목록, 코스 비용에서 혜택 차감은 제외한다.

## 변경 범위

- [화면 구조](../dist/index.html): 동선 중심 제목과 역 이미지, 요약 우선 배치, 독립 혜택 탭으로 가는 쿠폰 안내, 접는 이름/입력 조건, 혜택 조건 저장 안내·고급 필터 정리.
- [화면 동작](../dist/app.mjs): 스냅샷 기반 3칸 요약, 역·구간·경험의 연속 경로, 경험의 근거·위로·아래로·빼기. 연속 교통/도보 구간은 경험 사이에 묶되 각각의 시간·중간 역·미확인을 보존한다. 제목 오류로 경로가 사라지지 않고, 접힌 이름 수정은 오류 시 열어 초점을 준다.
- [스타일](../dist/styles.css): 흰 코스 바탕, 코발트 세로 경로, 44px 편집 조작, 생성 이미지 배치와 쿠폰의 점선·반원 홈. 홈은 혜택 안내/티켓에만 있다.
- [로컬 서버](../scripts/serve.mjs): 기존 공개 파일 허용 목록에 PNG 형식만 추가했다. [기존 서버 검사](../tests/server.test.mjs)에 3개 이미지 응답·MIME·PNG 서명 검사를 포함했다.
- 이미지: [역](../dist/assets/station.png), [정원](../dist/assets/garden.png), [서가](../dist/assets/bookstore.png). 기존 로고·하단 탐색 아이콘을 보존했다.

추천·공식 혜택 판정·원문 확인일·저장 모듈과 키는 변경하지 않았다. 과거 코스의 당시 입력과 현재 혜택 비교 조건도 별개다. 이전 코스에 동선이 없거나 구간 값이 `null`이면 이동/비용을 추정하지 않는다.

## 캡처와 시안 비교

[코스 상단](design-2026-10-27/course-top-final.png), [코스 쿠폰](design-2026-10-27/course-coupon.png), [혜택 상단](design-2026-10-27/benefits-top.png), [혜택 티켓](design-2026-10-27/benefit-ticket.png), [320px](design-2026-10-27/course-320.png), [1440px](design-2026-10-27/course-1440.png).

시안과 현재 캡처를 [같은 비교 입력](design-2026-10-27/qa-comparison.png)에 배치했고 [쿠폰 부분 비교](design-2026-10-27/qa-coupon-comparison.png)도 확인했다. 초기의 중복 입력 요약과 길어진 연결 행은 정리했다. 이미지 밀도와 화면 상태의 차이는 [메타데이터](design-2026-10-27/capture-metadata.json)와 [디자인 확인 기록](../design-qa.md)에 구분한다. 시안과 앱의 픽셀 일치나 실기기 검사를 주장하지 않는다.

실제 구간 이름·시간과 기존 저장/확인 행동을 보존하므로 한 화면에 모든 내용을 축소하지 않고 세로로 읽는다. 시안의 155분·30분·24,000원을 복사하지 않았다. 확인한 저장 코스는 가상 총시간 154분·가상 도보 49분·1인 6,000원이며 이 값은 실여행 계산이 아니다.

자동 검사의 임시 서버는 검사 안에서 종료된다. 수동 확인에 사용한 `127.0.0.1:4177` 서버와 현재 코스 탭은 사용자 미리보기로 남긴다. 표준 `4173` 저장 공간에는 새 검사 코스나 설정을 쓰지 않았다. [실제 화면 요약](design-2026-10-27/preview.png)은 생성 시안이 아니라 코스 상단과 쿠폰의 브라우저 캡처를 나란히 놓은 것이다.

## 남은 검증 범위

실제 휴대폰·가상 키보드·화면 낭독기·안전 영역 모의·OS 동작 줄이기/다크 환경·브라우저 완전 종료 후 재시작은 미실행이다. 구간 누락·과거 저장본은 도메인/저장 자동 검사와 코드 경계에서 보존했으며 이번 브라우저에서 모든 누락·저장 손상·할당량 오류를 주입한 것은 아니다. 공식 혜택 원문·실시간 모집·좌석·개인 수혜는 재확인하지 않았다. 외부 배포·유료 가입·예약/결제·Git 커밋/푸시는 수행하지 않았다.
