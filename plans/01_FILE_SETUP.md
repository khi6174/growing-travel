## 2. 원문 보존과 병합 판단

첨부 원본은 수정하지 않았다. [CODEX_START 사본](../handoff/growing-travel/CODEX_START.md)과 [PDF 사본](../handoff/growing-travel/growing-travel-service-guide-ko.pdf)을 별도 보존했고 각각 원본·사본 SHA-256이 일치했다. 해시는 [출처 장부](../docs/00_DECISIONS_AND_SOURCES.md)의 S02/S05에 기록했다.

기존 파일이 없어 기존 문서나 사용자 변경분을 덮어쓰지 않았다. 현재 docs는 신규 작성본이다. S01·S02·S05의 제품 중심은 일치한다. 초안을 PDF와 비교한 뒤 지역 필수 입력을 목적지 선택/미정으로 바꾸고, 방문 조건·장단점·작성자 AI 초안 확인·공개 운영 제안을 보완했다. PDF가 제시한 네 시험판 기능은 사용자의 첫 과제 범위에 맞춰 순차 개발로 분리했다. 제안 수치·유료화 방향을 확정 목표나 실적으로 옮기지 않았다. 상세는 [PDF 반영 대조표](../docs/07_SOURCE_REVIEW.md)에 있다.

별도 패키지 docs와의 충돌 여부는 판단 불가다. 해당 원문이 도착하면 보존 → 비교 → D/P/Q 분류 → 필요한 부분만 병합 → 검사 재실행 순서로 처리한다.
