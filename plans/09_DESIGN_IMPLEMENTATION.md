# 디자인 전달 반영 · 로컬 시연 기록

작성 기준: 2026-10-26 (Asia/Seoul). 상태: 문서 기준 로컬 디자인 반영과 아래 자동·브라우저 검사 완료. 자동 검사 78개, 변경 모듈 구문 검사와 최종 문서 정적 검사 통과. 과거 72개 자동 검사나 이전 시연 PNG를 새 화면의 통과 증거로 재사용하지 않았다.

## 요청과 확인 범위

사용자가 Claude와 디자인을 정의한 뒤 [디자인 개발 전달](../handoff/claude/DESIGN_HANDOFF_2026-10-26.md)을 확인하고 작업을 진행하도록 요청했다(S16·D18). [작업 기준](../AGENTS.md), [README](../README.md), 기준 docs, 전달 문서와 기존 로컬 구현·저장 계약을 읽었다. `git status --short` 결과 현재 `C:\성장 여행 서비스`는 Git 저장소가 아니다. 따라서 Git 기준 변경분 비교는 할 수 없으며 기존 파일과 사용자 전달 원문을 보존하면서 필요한 부분만 병합한다.

비공개 Claude 캔버스의 원본·화면 픽셀은 확보하지 않았다. 이번 작업은 전달 문서에 적힌 구조·색·상태·접근성 기준을 기존 로컬 시연에 반영하며 픽셀 일치나 최종 디자인 승인·실기기 검사 완료를 주장하지 않는다. 혜택 공식 공고를 재조사하는 작업이 아니며 기존 자료 확인일과 확인 수준을 유지한다.

## 사용자 결정과 구현 선택

사용자가 정한 방향은 D16 여행 티켓 B안·흑연 `#202124`·코발트 `#3651E8`, D17 대학생을 비교 조건으로 유지하고 공식 학생 경로 표시·필터를 두는 방식이다. 전달서의 나머지 제안과 미확정 질문은 사용자 결정으로 승격하지 않는다.

이번 구현 선택 P22는 다음과 같다.

- 티켓 절취선 위에는 개인 조건 상태와 이유, 아래에는 공고 상태·기간·출처를 표시한다. 접힌 카드에도 판단에 필요한 짧은 이유와 공고 기간을 남기고 한 번에 하나씩 펼친다.
- `shortReason`은 실제 비교 결과에서, 학생 경로는 공식 근거가 있는 기존 조건 규칙에서 계산한다. 자료에 없는 학생 우대나 수혜 확정 표시를 만들지 않는다.
- 조건 수정 시트는 별도 초안을 두고 ‘이번 비교에만 적용’과 ‘내 설정에 저장하고 비교’를 구분한다. 미적용 초안은 닫아도 같은 실행 중 보존하며 새로고침 또는 현재 개인 설정 변경 때 초기화한다. 오류·저장 실패는 초안을 보존한다.
- 현재 개인 설정·관심·걷기 선호는 재열람한 과거 코스와 별도로 보관한다. 설정 저장 시 기존 선호를 유지하며 과거 코스의 당시 입력·근거·저장 키는 바꾸지 않는다.
- 전체 조건 비교는 네이티브 `dialog`, 요약 펼치기는 `button`과 `aria-expanded`·`aria-controls`로 구성한다. 필터·결과 수·저장 결과·순서 이동과 초점 복귀를 점검한다.
- 공통 화면에 흑연/코발트와 5단계 표시를 연결하고 저장 성공 후 목록 알림, 저장 목록의 `ul`·전체 카드 링크, 빈 목록·읽기 실패 안내를 제공한다.
- 숫자 입력 범위는 기존 계약을 유지한다. 90% 같은 임의 한도 근접 판정과 새 연령·학적 인증은 추가하지 않는다. 외부 글꼴을 불러오지 않고 로컬 대체 글꼴을 사용한다.

세부 선택 이유는 [로컬 시연 결정](../docs/08_LOCAL_DEMO_DECISIONS.md), 사용자 결정·제안의 구분은 [장부](../docs/00_DECISIONS_AND_SOURCES.md)에 남긴다. 하단 메뉴 4개는 계속 현재 시연 기준이며 최종 정보 구조 확정이 아니다.

혜택 폭 360/390/430px에서 스크롤바를 제외한 문서 폭은 각각 345/375/415px이며 스크롤 폭과 같았다. 표시 중인 버튼·링크·summary의 조작 영역을 검사해 44px 이상을 확인했고 브랜드 링크와 수정 버튼의 부족한 영역을 보완한 뒤 재검사했다. 혜택 주요 본문 최소 글자 12px, 390px 코스 화면의 가로 넘침 없음도 확인했다. 수집된 브라우저 오류·경고 로그는 0건이다. 이는 해당 브라우저 상태의 검사이며 모든 화면·실기기의 포괄적인 접근성 인증이 아니다.

이번 화면 증거는 [혜택 티켓](09_BENEFIT_TICKET.png), [조건 시트 오류](09_CONDITION_SHEET.png), [코스 편집](09_COURSE_SCREEN.png), [저장 목록](09_SAVED_SCREEN.png)이다. 티켓 이미지는 23세·서울·대학생의 임시 적용, 조건 시트는 나이 0 오류의 390px 사례다. 실제 사용자 개인정보나 실제 여행 성과를 담지 않았다.

전용 `4175` 출처에는 검사한 가상 코스 1개와 가상 개인 설정을 남겼으며 삭제하지 않았다. 검증 종료 뒤 시험 서버를 Ctrl+C로 중지하고 임시 뷰포트를 초기화했으며 시험 브라우저 탭을 닫았다. 내 설정으로 돌아왔을 때 과거 코스 안내가 남던 문구도 현재 저장 설정 안내로 고친 뒤 구문 검사와 브라우저의 현재 안내·걷기 120분 유지 확인을 수행했다.

## 남은 범위와 전달서와의 차이

혜택 목록은 로컬 정적 모듈에서 동기적으로 읽으므로 인위적인 로딩 스피너를 추가하지 않았다. 현재 추천 출력은 경험별 제외 사유 목록을 제공하지 않으므로 전달서의 ‘조건 때문에 뺀 경험 보기’는 새 이유를 만들어 구현하지 않았다. 기존 추천·근거를 유지하며 제외 사유 출력은 후속 계약 검토가 필요하다.

실제 휴대폰·가상 키보드·화면 낭독기·브라우저 완전 종료 후 재시작, 저장 실패/손상·다중 탭 충돌의 실제 UI 주입은 미실행이다. 자동 저장 오류·호환 검사는 실제 UI 실패 검사를 대신하지 않는다. 혜택 원문 갱신·정부 혜택 신청·잔여 수량·개인 수혜는 별도 검증 범위다. 배포·유료 가입·Git 커밋·푸시·외부 예약/결제·Claude 업로드·메시지 전송은 이번 작업에 포함하지 않는다.
