# 다국어·외국인 유학생 확장 (2026-11-05, D53)

상태: 사용자 결정에 따른 계획과 단계 기록. 번역은 작업자가 쓴 초안이라 원어민 확인 전이다(Q20).

## 결정 (D53)

멘토링 피드백("다국어 버전으로 만들어서 외국인들이랑 외국인 유학생들이 한국 여행 추천, 대학가 주변 거리 추천")을 받아, 사용자가 **(가) 지금 타깃(자차 없는 대학생)에 외국인 유학생을 더하는 방향**으로 정했다. "외국인 전용 플랫폼으로 전환하지 않는다"는 원칙은 그대로다. 언어는 한국어에 더해 **영어·중국어·베트남어·일본어·미얀마어**. 일정 제약 없이 시작한다.

## 방식

- `dist/i18n.mjs`: 언어 목록, 고른 언어(이 기기 `growing-travel.lang.v1`, 처음엔 브라우저 언어), `t(키, 한국어, 값)`. 한국어 문장은 코드 안에 그대로 두고 다른 언어만 `dist/i18n/<언어>.mjs` 사전에 둔다. 사전에 없으면 한국어로 보인다.
- 정적 화면 문구는 `data-i18n`(글자), `data-i18n-aria`(읽기 이름), `data-i18n-placeholder`로 표시한다.
- 언어는 첫 시작 맨 앞과 화면 위 언어 단추에서 고른다.
- 장소 이름은 카카오·TourAPI의 한국어 그대로 둔다(간판·길찾기와 맞추려고). 종류·안내 문구는 번역한다.
- 혜택은 한국 거주자 기준이 많아 외국어로 볼 때 "외국인은 조건 확인 필요"를 붙인다.
- 미얀마어는 Pretendard에 글자가 없어 기기 글꼴(Noto Sans Myanmar 등)로 보인다.
