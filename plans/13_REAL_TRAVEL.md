# 13. 실제 여행 계획·저장 적용 기록

작성일: 2026-10-27. D24는 서울 출발 춘천·가평·강릉의 실제 장소·대중교통 동선과 저장, 여행자용 디자인·문구 정리 요청이다. P28은 구체적인 구현 선택이다. 이전 [MVP 디자인 적용](12_WIREFRAME_TO_MVP.md)과 검사 기록은 보존하며 새 기능의 통과 근거로 재사용하지 않는다. 작업 폴더의 `.git` 부재를 직접 확인했으며 Git 비교·커밋·푸시는 수행하지 않았다.

## 반영 범위

- 청량리·서울·용산 출발과 춘천·가평·강릉, 실제 장소 8개를 기본 추천에 연결한다. 주소·운영 안내·공식 출처를 장소 상세에서 확인한다. [출처와 한계](../docs/13_REAL_TRAVEL_SOURCES.md)에 정적 정보·미확인·좌표 출처를 구분했다.
- 출발역→지역역→선택 장소들→지역역→출발역의 동선을 표시한다. 대중교통/도보 길찾기·코레일 확인 링크를 제공하고 구간별 시간을 직접 입력할 수 있다. 현재 출발역 3개·지역역 3개·장소 8개의 좌표는 모두 있다. 서울역은 Wikidata 대표점, 관아는 종료된 공식 행사 페이지의 임영관 주소·지도 대표점으로 출처와 범위를 구분한다. 과거 저장본 등 좌표가 없는 경우의 장소 검색 대체는 유지한다.
- 미확인 교통비·도보량·이동 시간은 `null`이다. 왕복 모든 구간 시간을 입력한 경우에만 체류 계획과 합산한다. 순서 변경 후 일치하는 구간의 입력만 반영한다. 계획 시간은 실제 운행 시각 검증이 아니다.
- 화요일 휴무가 확인된 스카이워크를 해당 요일의 추천에서 제외한다. 휴무 정보 없음이나 계단 미확인을 운영·접근성 확인으로 승격하지 않는다.
- 동선 중심 구성·혜택 전용 쿠폰을 유지하고 기술 문구와 긴 설명을 줄인다. 필요한 불확실성·출처는 짧은 안내와 상세로 옮긴다. 새 실제 코스에는 가상 장소 이미지를 사용하지 않는다.
- 명시적 localStorage 저장·기존 키·버전·요청 이력·당시 스냅샷을 유지한다. 과거 코스는 ‘이전 예시 코스’로 재열람하며 현재 설정으로 자동 덮어쓰지 않는다. 공식 혜택은 별도 안내이고 실제 비용에서 자동 차감하지 않는다.

구현 경계는 [적용 계약](real-travel-2026-10-27/IMPLEMENTATION.md), 모듈은 `dist/real-catalog.mjs`, `travel-domain.mjs`, `travel-journey.mjs`, `travel-links.mjs`, `real-travel-view.mjs`와 기존 앱·저장 검증 분기다. 기존 가상 도메인과 저장본의 해석은 보존한다.

## 남은 한계

실시간 교통 API·열차/버스 시간표·운임·도보 거리·여행 당일 영업·현장 방문을 검증하지 않았다. 외부 지도는 사용자 확인 경로이며 링크가 있다는 사실로 실제 이동 가능·귀가 보장을 표시하지 않는다. 모든 입력 시간이 채워져도 실제 교통 사정에 대한 보장은 아니다. 주소와 일부 운영 안내가 확인된 실제 장소 목록이지 실제 후기·별점·방문 인증 자료가 아니다.

계정·서버 DB·동기화·공개 기록·후기·게시판·실기기·예약·결제·유료 가입·운영 배포·Git 커밋/푸시는 이번 범위 밖이다. 기존 혜택 원문의 현재성을 이번 실제 여행 자료 조사로 갱신한 것으로 기록하지 않는다.
