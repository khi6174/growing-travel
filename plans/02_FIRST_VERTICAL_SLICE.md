# 첫 개발 과제: 상황 입력 → 경험 추천과 근거 확인 → 코스 저장

상태: **로컬 최소 시연 코드 작성·자동 검사 21개 통과, 실제 화면 검증 미실행**. 사용자 결정 D06·D09와 확보한 CODEX_START·PDF를 반영했다. 별도 전달 패키지 docs 원문 미확보. [결정 장부](../docs/00_DECISIONS_AND_SOURCES.md)의 P01~P14와 Q02~Q06을 확인한다. [구현·검사 기록](03_LOCAL_DEMO_IMPLEMENTATION.md)에 실제 결과와 제한을 남겼다.

## 사용자 결과

여행자는 가능 시간·관심을 입력하고 목적지는 선택하거나 미정으로 둔다. 추천된 경험이 왜 자신의 상황에 맞는지, 방문 당시 조건과 장단점은 무엇인지 확인한 뒤, 선택한 경험의 순서를 바꾸고 코스로 저장하여 다시 열 수 있다. 지역·이동 근거가 부족하면 코스 가능 여부는 미확인으로 표시한다.

## 이번 시연의 최소 선택

- Q02의 시연 범위: 한국어 화면, 가능 시간·관심 필수, 목적지 선택/미정 및 동행·이동·계단 회피 선택. 모든 지역과 경험은 가상으로 표시한다. 운영 고객군·지역의 확정은 아니다.
- Q03의 시연 범위: HTML/CSS/브라우저 JavaScript 모듈과 기존 Node.js의 정적 로컬 서버를 사용한다. 패키지 설치·빌드·외부 서비스 없이 시작한다.
- Q04의 시연 범위: 같은 브라우저 프로필·같은 주소의 localStorage. 새로고침과 브라우저/서버 재시작 후 저장본 재열람을 목표로 하되, 삭제·비공개 모드·다른 주소의 저장소 차이는 명시한다. 계정·동기화·다중 사용자 인증은 포함하지 않는다.
- P05를 시연에 채택: 가상 표시가 있는 경험 자료와 규칙 기반 추천으로 흐름을 검증한다. 실제 AI·실제 장소 검증 완료를 의미하지 않는다.

이 선택들은 D09의 범위 안에서 구현자가 채택한 P14이며, 근거와 한계는 [로컬 시연 결정](../docs/08_LOCAL_DEMO_DECISIONS.md)에 기록한다. 운영 서비스의 미확정은 남아 있다.

실제 데이터나 외부 모델을 바로 사용하려면 Q05·Q06을 먼저 해결한다. 외부 계정·모델 선택 없이도 논리 계약과 흐름 검증은 준비할 수 있다.

## 작업 카드

| 작업 | 입력 → 처리 → 결과 | 연결된 기준 |
| --- | --- | --- |
| DEV01 | 상황 입력 → 필드/시간 유효성 검사 → 요청 스냅샷 | F01, UX01, AC01 |
| DEV02 | 허용 경험·근거 → 추천 및 응답 검증 → 목록/근거/불확실성 | F02, UX02~UX03, AC02~AC04, AC08 |
| DEV03 | 사용자 선택 → 순서·제거·시간 재계산 → 코스 초안 | F03, UX04, AC05 |
| DEV04 | 코스 초안 → 소유권·중복·버전 확인 → 저장 및 재열람 | F04, UX04, AC06~AC08 |
| DEV05 | 정상/오류/가상 표시/권한 시나리오 → 실제 실행 → 증거와 한계 기록 | AC01~AC08 |

세부 입력·출력은 [데이터 및 AI 계약](../docs/03_DATA_AND_AI_CONTRACT.md)을 따른다. 화면별 복구 동작은 [화면 흐름](../docs/02_UX_FLOWS.md)에 맞춘다.

## 범위와 완료

첫 과제에는 개인 기록 작성·공개·방문 후 확인·다음 추천 반영 화면을 포함하지 않는다. 다만 출처·가상 여부·소유권·공개 범위 필드를 손실 없이 유지해 후속 확장을 가능하게 한다. 자동 예약·결제는 제품 방향 밖이다.

완료 제안: AC01~AC08의 적용 가능한 검사를 실제 실행하여 통과하고, 선택·순서·근거·가상 표시를 유지한 저장본 재열람을 증명한다. AC08의 계정형 전용 검사는 Q04가 단일 사용자 로컬 저장일 때만 해당 없음으로 이유를 남긴다. 사용한 자료, 실행 명령, 환경, 저장 유지 범위, 미실행 항목을 함께 보고한다. 가상 자료로 실행했다면 ‘시연 흐름 구현’으로만 기록한다.

우선 브라우저 도구 제한으로 수행하지 못한 화면 검증을 마친다. 그다음 개인 기록(AC09) → 선택적 공개·방문 후 확인(AC10~AC12) → 다음 추천 반영(AC13) 순서로 이어간다. 현재 1단계 구현 파일과 자동 검사 결과를 남겼으며, 전체 AC 수용 완료로 표시하지 않는다. 후속 단계는 이번 구현에 포함하지 않는다.
